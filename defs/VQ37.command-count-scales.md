# VQ37 local VVEL command-word counts

## Claim and image bindings

The local claim of `vvel_command_shaft_angle/tbl` and
`vvel_command_shaft_angle_second/tbl` is `count = u16(lookup ordinate)`:
16x1 `uint16`, unit `count`, scale `x`, inverse `x`, identity and scale level

output, or a complete task result. A sign-extended wide register is not the

## Real lookup and representation boundary

The actual calling convention is R4 = values, R5 = axis, R6 = coordinate.
The lookup truncates its coordinate to an unsigned word. JK78C and 1ND
wrappers retain the values pointer across the real axis search; the result
passes through the real division and integer finisher without a stub.

| Layout | Primary path | Second path |
|---|---|---|
| `jk78c` | `28320 -> 287ac -> 28aa0 -> 28568` | `28510 -> 289ac -> 28b38 -> 28920` |
| `1nd` | `2893c -> 28dc8 -> 290bc -> 28b84` | `28b2c -> 28fc8 -> 29154 -> 28f3c` |
| `1me3b` | exact/end-point leaf `2af88` | exact/end-point leaf `2bcd4` |

For unequal axis points and a fractional JK78C/1ND coordinate, the actual
unsigned divider establishes
`phase = floor((coordinate - x0) * 65536 / (x1 - x0))`. The real finisher
returns `y0 + floor((y1-y0)*phase/65536)` for ascending/equal ordinates, or
`y0 - floor((y0-y1)*phase/65536)` for descending ordinates. Assertions outside
the execution helpers compute the independent reference. MACL/MACH and stack
guards bind preservation; real return and call slots remain in the trace.
Separate direct calls execute the integer helper's zero/nonzero-divisor
branches with independent numerator/divisor seeds and retained R2/stack
state. The zero-divisor branch is a helper contract, not a claim that a
fractional stock lookup reaches it.

The 1ME3B exact return executes `MOV.W @R4,R0` in the RTS delay slot. Thus
`32768` and `65535` return as `ffff8000` and `ffffffff` in wide R0. The actual
caller `EXTU.W` yields the same unsigned low word as the JK78C/1ND path.
1ME3B fractional lookup uses FPUL/float at `0002b078` and `0002bdc4` and is
outside execution. No integer substitute or floating-point result is seeded.

### Duplicate points and the additional read

The last five stock axis points are all `15536`; the last five ordinates are
all `37351`. Repeated coordinate probes select physical index 15. They do not
prove distinct visits to cells 11 through 14. Calibration-only overlays use a
strictly increasing synthetic axis `1000 + 4000*i` to execute all 16 physical
cells, including distinct high-bit and boundary ordinates. These overlays
establish local word representation and lookup behavior, not the meaning of
the stock physical coordinate.

JK78C and 1ND wrappers actually read `table[16]` at the upper endpoint:

| Layout / pair | Instruction | Address | Width |
|---|---|---|---|
| JK78C primary | `00028332` | `0001571c` | 2 bytes |
| JK78C second | `00028522` | `0001b02a` | 2 bytes |
| 1ND primary | `0002894e` | `00015c42` | 2 bytes |
| 1ND second | `00028b3e` | `0001b67e` | 2 bytes |

The gate asserts the actual read width/address and phase-zero output
independence across representative next-word values, including both finisher
branch outcomes. It does not prohibit that read or call it a firmware defect.
The 1ME3B exact leaf reads only the selected ordinate. An additional-word
overlay is separate from the declared 16 table cells.

Coverage includes exact stock points, stock upper endpoints, seven stock
integer fractional coordinates, all synthetic physical cells, three interior
fractional displacements in each unequal synthetic interval on JK78C/1ND,
ascending/equal/descending ordinates, coordinate upper-bit aliases, and
representative uint16 boundaries `0,1,127,128,255,256,32767,32768,65534,65535`.
This is not exhaustive uint16 execution.

are outside the proof. Omitted primary prologue state and the two coordinate
arguments are independent slice inputs, not measurements or input producers.

## Task pointer roles and real stores

The integer task slices begin after the floating-point producer. The first
call uses the command-word table as **axis** and the paired coordinate array
as **values**. Local bounds produce the first stored word. The second call
exchanges the roles: command words are **values** and the paired coordinates
are **axis**. The returned low word reaches the second real word store.

| Layout | Task slice, end exclusive | First call: values / axis | Bound store | Second call: values / axis | Result store |
|---|---|---|---|---|---|
| `jk78c` | `[000556d8,00055784)` | `000556e2`: `156dc` / `156fc` | `0005576c`: `ffff44aa` | `00055776`: `156fc` / `156dc` | `00055782`: `ffff35ba` |
| `1nd` | `[0005e87e,0005e8fc)` | `0005e886`: `15c02` / `15c22` | `0005e8e6`: `fffeb7ba` | `0005e8f4`: `15c22` / `15c02` | `0005e8fa`: `fffea7d2` |
| `1me3b` | `[000623d2,0006244e)` | `000623da`: `15a56` / `15a76` | `0006243e`: `fffeb91a` | `00062444`: `15a76` / `15a56` | `0006244c`: `fffea8c0` |

The narrow declaration gate binds the diagram and paragraph in
`JK78C.vvel.md` to these executed arguments, delay slots, and stores. It does
not validate that document's other physical-unit claims or execute the latch
and DID chain. These raw pointer roles do not establish physical units.

Bounds, the incoming coordinate, and the state byte are independent slice
inputs. JK78C reads its word bounds from entry SP+`114`, `11c`, `f8`, `118`
and its state byte from SP+`100`; its other lower bound comes from `ffff380c`.
1ND/1ME3B read SP+`bc`, `9c`, `a4`; 1ND seeds R10/R13 and `fffeaa78`, while
1ME3B seeds R9/R11 and `fffeaba6`. The 1ND GBR base is loaded by its real
`[0005e2b2,0005e2b6)` instructions and literal `[0005e570,0005e574)`; intervening
prologue instructions are not executed. Tested bounds stay below `32768` and
at exact coordinate points where 1ME3B executes no fractional float path.
The gate executes both outcomes of each selected local bounds/state branch,
including real delayed branches, and observes zeroing of the adjacent word.
It does not prove generation of bounds, preceding float conversion, complete
task reachability, or full-domain bounded outputs.

## Evidence and negative contracts

Snapshot mutants reject each retained span independently. Executed mutants
omit snapshot binding and challenge coordinate extension, ordinate width,
return/call slots, real integer phase/division/finisher arithmetic, MACL/stack
preservation, table pointers, result extension, spill width, task pointer
roles, local bounds branches, and store widths. Mutant execution occurs outside
an expected assertion failure; an unsupported opcode is not a passing negative
result. 1ME3B integer-helper/fractional mutants and primary spill-width
mutants are explicitly skipped: those paths or stores are outside their
selected slices, not successful mutant executions. The unchanged primary
PathSh2 is the sole execution path, without new opcode handlers, stubs,
alternative runners, or manual result publication.

## Exclusions

Excluded: 1ME3B fractional lookup and float consumers; primary input producers;
float normalization and the second-copy mean; whole-function reachability;
complete VVEL task selection and bounds generation; physical units or physical
axis scaling; DID `125c` and latch execution; actuator behavior; hardware
validation; and flashing eligibility. Local software gates do not establish
silicon behavior or replace static audit and bench/vehicle validation.
