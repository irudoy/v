# Native VQ37 timing-state addend byte-count scale

`timing_state_addend_alternate/tbl` is an eight-cell `uint8` table. Its local
sample is **u8(lookup ordinate)-128**, established at the actual byte store
and subsequent signed byte read. The owner retains
`unit = "Timing-state count"`, `scale = "x-128"`, `to_raw = "x+128"`, and
`scale_level = "code"`.
This is not a wide-register sample and does not establish an ignition-angle,
RPM, or physical time unit.

only in the executable fixture; each catalog image is loaded and checked
against its own lock, including both images of the `1nd` layout.

## Actual implicit-byte lookup

| Layout | Actual lookup path | Retained kernel spans, end exclusive |
| --- | --- | --- |
| `jk78c` | `00028198 -> 000288a8 -> 00028568` | `[00028198,000281b0)`, `[000288a8,000288e8)`, `[00028568,00028596)` |
| `1nd` | `000287b4 -> 00028ec4 -> 00028b84` | `[000287b4,000287cc)`, `[00028ec4,00028f04)`, `[00028b84,00028bb2)` |
| `1me3b` | Inline leaf `0002a9f4` | `[0002a9f4,0002aa46)` |

The interior entries `000288a8` and `00028ec4` execute five shift/carry pairs.
The earlier entries of their containing functions are outside the gate.
Each layout independently yields the following arithmetic for `c = u8(index)`:

- For `c >= 224`, return cell 7 by `MOV.B` in the `RTS` delay slot.
- Otherwise, `i = c >> 5`, `f = c & 31`, and both adjacent ordinates are
  unsigned bytes. The phase is `f << 11`; it is an interpolation weight, not
  the ordinate unit.
- Ascending or equal: `y0 + floor((y1-y0)*f/32)`.
- Descending: `y0 - floor((y0-y1)*f/32)`.

Interior wide returns are unsigned `0..255`. The endpoint wide return is the
sign-extended byte, while its low byte remains the ordinate. Neither wide
representation is the centered sample. MACL and MACH are preserved. The
JK78C and 1ND descending paths balance a four-byte push/pop; the 1ME3B leaf
has no stack writes.

## Consumer boundaries

The fixture starts inside the alternate-table arm, after the upstream
selection predicates. It records the actual table pointer and callee target
before `JSR`, then executes the actual callee and its return before continuing
to the actual byte store. Only the following scoped consumer slices are
included; they are not whole-function reachability proofs.

| Layout / mode | Entry, table binding, call | Bias and byte store | Signed sample and local use |
| --- | --- | --- | --- |
| JK78C configuration bit 0 clear | `000646c8`; load `000646ce` from literal `0006484c`; call `00064748` | `00064790..0006479c`; add `00064796`; store `0006479a` to `ffff14e5` | `00064a02..00064a08`, signed load `00064a06`; independent incoming add at `00064a0a` |
| JK78C configuration bit 0 set | `000646c8`; same binding; call `000646dc` | Return at `000646e0`; add `000646e6`; store `000646ea` to `ffff14e7`; stop `000646ec` | `00064734..00064738`, signed load `00064736`, before the minimum with a separate correcting result |
| 1ND0A and 1ND3B | `0006f512`; load `0006f514` from literal `0006f6fc`; call `0006f51a` | `0006f572..0006f580`; add `0006f578`; store `0006f57e` to `fffe8523` in the `BT/S` delay slot | Signed load `0006f7c8`; scoped unsigned incoming operand and add `0006f7ce..0006f7d2` |
| 1ME3B | `00073370`; load `00073372` from literal `00073404`; call `00073378` | `00073428..00073436`; add `0007342e`; store `00073434` to `fffe84e8` in the `BT/S` delay slot | Signed load `0007367c` and scoped add `00073682..00073686`; second signed load `0007384c` and add `00073852` within `0007384a..00073854` |

JK78C executes both configuration arms, with the original configuration byte
bound by the fixture and bit 0 varied in memory. In the bit-set arm the sample
is `ffff14e7` before the minimum, not a universal final `ffff14e5` result.
1ND and 1ME3B execute both taken and non-taken `BT/S` outcomes: the store
executes in both. Their actual `JSR` delay slots perform input `EXTU.B`.

Incoming unrelated state bases and bytes, GBR, and the later independent add
operand are explicit seeds. The source index producer, upstream selection
state machine, other calls, and skipped unrelated reader setup are not
reconstructed. The add operand is 165; the assertions retain the signed
sample separately from the resulting sum.

For every ordinate byte `raw` in `0..255`, the actual store and signed load
establish `sample = raw-128`, in `-128..127`, and `sample+128 = raw`. Byte
truncation is essential: upper return bits and pre-store wide arithmetic are
not the centered count. Arbitrary upper return bits are tested only as an
independent consumer-representation contract; those cases make no claim that
the real lookup can produce such wide values.

## Coverage and negative contracts

- Every input byte, including 0, 31, 32, 223, 224, and 255; high-bit aliases
  through actual input `EXTU.B`; unequal fractional ascending and descending
  cells, equal cells, and the actual stock curve.
- All 256 ordinate bytes through the actual table address, real lookup,
  actual byte store, and signed reader on interior and endpoint paths.
- Actual return and `RTS` delay slots, call and `BT/S` delay slots, register
  guards, balanced stack, adjacent RAM guards, exact load/store widths, and
  absence of a table[8] read.
- Executed lookup mutants for index extension, threshold, fractional phase,
  byte-load width, direction, return slots, MACL restoration, and stack use.
  Executed consumer mutants for table binding, bias, store/read widths,
  input-conversion slots, configuration choice, and delayed stores.
  Execution occurs outside the expected-failure assertion, so an unsupported
  opcode is not accepted as a successful negative test.
- Snapshot mutants reject each retained span independently. They do not
  substitute for the executed semantic mutants.
- A fresh compiled model requires the actual typed `scale` test evidence on
  each symbol, verifies its AST key, rejects a missing function key through
  `checks.homology`, and keeps identity-only or homology-only evidence from
  grounding the scale. Negative mutations are confined to that model and its
  original evidence is restored. Identity, unit, scale, inverse, code level,
  geometry, status, presentation, and links are preserved; the test neither
  writes the owner nor synchronizes the graph. AST matching and executable
  test results are separate contracts.

The static RPM axis in editor presentation, index producers, full selection
predicates, whole-function reachability, other lookups, correcting terms and
final outputs, a physical time unit or angle conversion, and hardware
validation remain outside this claim. The software gate establishes a local
count representation, not a flashing or hardware-validation result.
