# VQ37 throttled-duration ramp-delay count scale

## Claim and owner

`vvel_duration_throttled_ramp_delay/tbl` on `1me3b:0001457a` has unit
`count`, scale `x`, inverse `x`, and scale level `code`. The owner is
`kb/tbl/vvel_duration_throttled_ramp_delay.toml`. The count is the local
unsigned-byte delay calibration ordinate, not a time value. One ordinate
count contributes 100 increments to the helper threshold after initialization.
The multiplier belongs to the consumer; the editor scale is not `x*100`.
The role is absent on `1nd` and `jk78c`, not relocated to those layouts.

restores the unsigned-byte ordinate. `00063562..00063564` computes

The identity transformation `x` is tied to actual byte lookup and unsigned
interpretation, not accepted merely because it is an arithmetic identity.
Its delay-count role also requires the threshold binding and counter contract
below. The current multiplier does not make a retained threshold equal to a

## Separate executed threshold consumers

Each consumer has an explicitly independent incoming R11, threshold, counter,
previous flag, and mode. The input is not an assertion that a skipped float
interval produced that state. The integer mode predicate at `000635a8..000635ae`
executes; the following BT/S has a float delay slot and is excluded. The
selected consumer entry is an explicit input to the separate slice.

- The zero-mode arm `000635b4..000635cc` preserves the incoming threshold,
  reads `fffef4dc`, and passes it in R6 to the actual call `000635ca`.
- The nonzero-mode arm `00063664..00063686` writes the independent R11 to
  `fffef4dc` only when the previous flag `fffef4e2` is zero. A nonzero flag
  retains the old threshold, independently of R11. The actual call is
  `00063684`, with `MOV R0,R6` in its delay slot `00063686`.
- Both arms pass a Boolean mode in R4, flag address `fffef4e2` in R5,
  threshold in R6, and counter address `fffef4d8` in R7. The full integer
  helper executes and returns to `000635ce` or `00063688`, before the next
  float consumer.

The positive scale test checks the initialized threshold against `100*x`
using an independent incoming consumer value. The real publication/read/call
instructions and the fixed static connection supply the binding. A standalone
helper with an opaque threshold, without that binding, is not scale evidence.
Adjacent sentinels establish byte/longword widths and local write boundaries.

## Counter contract

For `0002861e`, let `a=u8(R4)`, `f=u8(*R5)`, `D=u32(R6)`, and `C=u32(*R7)`.
The helper performs one counter update per invocation:

- If `a=0`, it writes counter zero and returns zero.
- If `a!=0` and `f=0`, it writes counter zero and returns `D==0`.
- Otherwise it computes `n=(C+1) mod 2^32`. If `n<D` and `n!=0`, it writes
  n and returns zero. Otherwise it writes D and returns one.
- Every path writes `*R5=a`; the RTS delay slot `00028656` puts the result
  from R2 into R0.

The comparison is unsigned. A uint32 wrap completes the wait and clamps the
counter to D; it does not restart the counter at zero. The gate covers reset,
fresh and retained flags, D=0, increment below/at/above the threshold, unsigned
boundaries, wrap, flag overwrite, and the branch/RTS delay slots. Large
independent thresholds are helper-domain probes, not claimed outputs of the
byte calibration. For a fresh initialized positive threshold `D=100*x`, the
first active invocation resets the counter, and D subsequent retained-active
invocations increment it to completion. For x=0, the fresh call completes.

## Negative checks and evidence matching

Retained snapshot mutants reject changed literals, registers, widths, branch
operands, delay slots, and the statically reviewed conservation instructions.
Separate executed mutants bypass the snapshot binder and change byte extension,
lookup width, multiplier, publication/read width, unsigned comparison,
increment, reset, flag overwrite, argument transfer, or the RTS result. They
exist only in test memory, not as patched firmware images. A signed or wide
intermediate can differ even where truncation preserves a later low byte;
the tests distinguish intermediate observations from final threshold changes.

The compiled owner keeps its identity and count-scale properties and carries
an actual typed item with `supports=scale`. The gate requires that exact item
and checks the named top-level test through the actual matcher. A temporary
in-memory missing key fails matching and the homology check; the original
owner evidence is restored. This negative check does not edit the owner or
synchronize the graph. The executable test is run separately from AST matching.

## Exclusions

Nonzero-fraction lookup enters FPUL/float arithmetic and is outside executable
coverage. The full `00063534` floating-point calculations, continuous behavior
between slices, incoming producers, mode reachability, and scheduler frequency
are not established. The local count is not physical time; no seconds per
count are assigned. The full duration approach and final actuator output are
outside this proof. There is no hardware validation or flashing-eligibility
claim. The primary interpreter remains unchanged.
