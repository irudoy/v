# VQ37VHR VVEL manual units and raw-word boundaries

The VQ37VHR section of Nissan publication SM3E-1V36U0, August 2012,
describes the 2013 G Sedan. Its physical quantities and service references
support the JK78C/1ND manual review. A factory quantity name does not assign
a transfer function to a ROM word or identify an internal ECM ADC channel.

The code mechanisms and hypotheses belong to [JK78C.vvel.md](JK78C.vvel.md)
and the native KB owners. This reconciliation records which physical claims
the factory source supports. It introduces no engineering conversion.

Addresses in the matrix below belong to JK78C. The 1ND meanings retain
their own target addresses and independently reviewed code bindings.

## Factory quantities and reference conditions

EC-162 distinguishes the control-shaft angle from VVEL position-sensor
voltage and learned sensor voltage. It does not describe valve lift in mm
or crankshaft valve-event duration as the VVEL TIM quantity.

EC-30..31 give the initial-position adjustment reference as 500 +/- 48 mV
for VVEL POSITION SEN. EC-556 gives approximate warm-idle and quick-rev
envelopes for the voltage and shaft-angle displays. These are distinct
quantities and conditions; their envelopes are not paired calibration points
for a raw angle word. The 5.5 deg actuator-arm setting in EM-243 is a
mechanical reference from the small-lift position, not a declared raw zero.

EC-213..214 measure MAP voltage at ECM F101 terminal 38 relative to F102
terminal 96. EC-393..394 measure booster voltage at F101 terminal 39 relative
to terminal 36. The atmospheric-pressure check waits at least one minute
after stopping the engine and accounts for local pressure/altitude. Vacuum
rows describe a voltage difference from the engine-stopped reading.

EC-412 describes the separate VVEL control module detecting shaft position
from sensor voltage and sending the signal to the ECM. EC-597..599 identify
the VVEL-module sensor terminals and supplies. These terminals do not
identify an ECM analog input.

## Evidence and acceptance boundary

Factory-manual provenance establishes quantity names, units and service
reference bands. Code provenance establishes addresses, access widths,
arithmetic and the declared latch/diagnostic paths. Agreement with a broad
factory band supports a candidate interpretation without selecting an exact
raw gain. No raw scale is promoted from a display name, table shape,
reverse lookup or similar numeric range.

EC-411, EC-412 and EC-489 describe the relevant VVEL DTC conditions without
numeric trigger thresholds for the reviewed raw words. The repository's
code thresholds and the manual's component-inspection bands retain their
separate meanings.

Board routing, the physical AN12 signal, ADC reference voltage, task periods,
sample age, live DID/display agreement and physical valve response remain
hardware acceptance work. The manual does not close those questions.
