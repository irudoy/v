# SH7059 input and engine-state paths

The stock 1ME3B and 1EK7A ROMs publish coolant and intake-air temperature
through independently bound acquisition and conversion functions. The
[sensor acquisition](SH7059.sensor-acquisition.md) describes the capture
registers and the multiplexed ADC entry points.

| Value or stage | 1ME3B | 1EK7A |
| --- | --- | --- |
| Coolant ADC sample | `0xFFFE8D18` | `0xFFFE8D2C` |
| Coolant conversion and fallback task | `0x00043304` | `0x000442FC` |
| Published coolant byte | `0xFFFE8079` | `0xFFFE809D` |
| IAT ADC sample | `0xFFFE8D0C` | `0xFFFE8D20` |
| IAT filter | `0x0004A07C` | `0x0004B3F4` |
| Filtered IAT ADC coordinate | `0xFFFE9924` | `0xFFFE996E` |
| IAT conversion and fallback task | `0x0004A0E2` | `0x0004B45A` |
| Published IAT byte | `0xFFFE9928` | `0xFFFE9972` |
| Two-channel airflow ADC acquisition | `0x0002EB72` | `0x0002F88E` |
| Right-aligned B2 ADC sample | `0xFFFE8D1C` | `0xFFFE8D30` |
| Airflow publication task | `0x00048CC0` | `0x00049FF0` |
| Published B2 sensor word and total airflow word | `0xFFFE8026`, `0xFFFEAE4E` | `0xFFFE802A`, `0xFFFEB186` |

The ADC scan reads and right-aligns ADDR0 for the coolant sample. The
coolant producer reads that sample, applies range and fallback selection,
and writes the published byte. The IAT filter copies the first sample and
uses `(3 * previous + sample) >> 2` on subsequent update passes, with a
one-count increment if truncation would otherwise leave a rising value
unchanged. The conversion uses an 8-bit curve or the fixed `0x4B`
fallback, then sets its publication flag.

The airflow publication task sends the bank-2 sample to the conversion
helper and stores the result. It separately multiplies the existing
airflow-state word by a calibration byte, shifts right by eight and
stores the saturated total. The layout bindings also expose the
bank-1 sensor word, base fuel schedule, and normalized load.

## Normalized load publication

The live producer computes `min(255, floor(BFS * 128 / reference))`
from the unsigned base-fuel schedule (BFS) word. The stock reference
word is `0x9F38` on both ROMs. The scheduler copies the byte as the
most significant byte of a longword into the input snapshot.

| Operation | 1ME3B | 1EK7A |
| --- | --- | --- |
| Read the BFS word | `0x000484C4` from `0xFFFE802E` | `0x000497F4` from `0xFFFE8032` |
| Read the reference | `0x0004853C` from ROM `0x000094D4` | `0x0004986C` from ROM `0x00009626` |
| Store the live byte | `0x00048554` to `0xFFFE8048` | `0x00049884` to `0xFFFE8068` |
| Copy to the snapshot | `0x00021298` and `0x000212DA` to `0xFFFE8034` | `0x0002130C` and `0x00021326` to `0xFFFE8050` |
| Read and pass to knock lookup | `0x00071D86` and `0x00071D98` | `0x0007336A` and `0x0007337C` |
| Read and pass to ignition lookup | `0x000799EE` and `0x00079A02` | `0x0007B0D6` and `0x0007B0EA` |

The two-axis lookup consumers zero-extend the snapshot byte. An
additional 1EK7A path reads it at `0x00080154` and passes
`min(2 * snapshot, 255)` to the lookup at `0x00080166`.

## Engine speed publication

On 1ME3B the speed scaler at `0x000420C8` reads `0xFFFE8176` and
stores the live RPM coordinate at `0xFFFE81D6`. The scheduler copies the
containing longword from `0xFFFE81D4` to `0xFFFE819C`, placing its low
word at `0xFFFE819E`. On 1EK7A the corresponding scaler at `0x000430B8`
reads `0xFFFE819A` and writes `0xFFFE81FC`. The scheduler copies the
containing longword to `0xFFFE81C4`, placing the RPM coordinate in its
high word. Both scaler tasks derive the coordinate by shifting the
high-resolution input right by six.

## Vehicle speed publication

Both periodic HCAN1 receive dispatchers select the meter-frame decoder
for packed key `0x5000` (standard identifier `0x280`). The decoder
joins payload bytes 4 and 5 of software record 19 in big-endian order
and stores the unsigned quotient by ten. The speed write requires bit 3
of the first selector, value 1 in the second and zero in the third. Both
stock images carry `3B 01 00` at the selector locations.

| Stage | 1ME3B | 1EK7A |
| --- | --- | --- |
| HCAN1 receive dispatcher | `00120830` | `00140E94` |
| Key comparison, branch and decoder call | `00120944`, `00120948`, `00120B56` | `00140FA2`, `00140FA6`, `0014116E` |
| Meter-frame decoder | `00121FA2` | `00142606` |
| Stock receive selector bytes | `00008331`, `00008337`, `000088F6` | `00008341`, `00008347`, `00008960` |
| Receive-record bytes and load sites | `FFFEB1B3/FFFEB1B4` at `00121FC4/00121FCA` | `FFFEB4E9/FFFEB4EA` at `0014262E/00142634` |
| Publish CAN-derived word | `FFFE8120` at `00121FEA` | `FFFE8144` at `00142654` |
| Vehicle-speed update and source read | `00044756` reads at `000447CC` | `0004585E` reads at `000458D4` |
| Filter history and write sites | `FFFE8140` at `00044804/0004481A/00044848` | `FFFE8164` at `0004590C/00045922/00045958` |
| Live coarse byte and store | `FFFE816C` at `000448BC` | `FFFE8192` at `000459CE` |
| Additional published byte and word | `FFFE8028` at `000448B8`, `FFFE802A` at `000448A4` | `FFFE802C` at `000459CA`, `FFFE802E` at `000459B6` |
| Scheduler block-copy call and source/destination | `0002133A`, `FFFE8100 -> FFFE808C` | `00021386`, `FFFE8124 -> FFFE80B0` |
| Previous-cycle coarse byte | `FFFE80F8`, block offset `0x6C` | `FFFE811E`, block offset `0x6E` |

The filter uses `(15 * previous + input) >> 4`. Input below 20 clears
the filter, and the rising branch increments an unchanged truncated
result. The quantizer divides the filtered word by 20 and clips it to
255. The additional byte receives the same value as the live byte. The
word beside it holds `floor(filtered * 2 / 5)`.

The copy helpers transfer `0x74` bytes. A DFCO consumer reads the 1ME3B
snapshot at `000367AC`. The fuel-cut coordinator reads the 1EK7A snapshot
at `0007BF28`. Bus timing, physical speed accuracy, and the separate
word's physical scale require independent evidence.

## Input endpoints

| HCAN1 receive stage | 1ME3B | 1EK7A |
| --- | --- | --- |
| Read mailbox status and copy payload | `0x0011F92E` | `0x0013FF92` |
| Periodic receive dispatcher | `0x00120830` | `0x00140E94` |
| Dispatcher pointer in stock schedule | `0x00021FAC` | `0x00022038` |

The mailbox handler reads `RXPR1_1` at `0xFFFFD840` and `RXPR0_1` at
`0xFFFFD842`, masks for the selected mailbox, and handles pending data
and remote-frame status. A periodic dispatcher consumes configured
receive records and branches on their identifier words.

The pedal and dual-throttle endpoints use the published APP and TPS
channel words. The steering-switch endpoint uses the debounced ASCD
switch code. Connector terminals and producers outside the verified
paths below require separate evidence.

## Throttle position acquisition

The paired ADC acquisition reads `ADDR18` at `0xFFFFF82C` on both ROMs.
On 1ME3B, the load at `0x0002ED82` is followed by an unsigned right shift
of six bits and a store to `0xFFFEAC0C` at `0x0002ED92`. The 1EK7A
counterpart loads at `0x0002FA9E` and stores to `0xFFFEAF3C` at
`0x0002FAAE`.

The 1ME3B secondary throttle conditioner `0x0004B524` reads
`0xFFFEAC0C` at `0x0004B55C` and publishes `0x0400 - sample` to
the bank-2 diagnostic word `0xFFFE9952` at `0x0004B564`. The
reference-corrected result at `0xFFFE994E` is a separate value. The
producer of the final 1EK7A diagnostic word `0xFFFE999E` remains open.

The 1ME3B primary bank-2 diagnostic word `0xFFFE994A` receives the
low halfword of the accumulator `0xFFFEAEAC` at `0x0004B8A6`,
`0x0004B9A8`, or `0x0004BBE4`. The mode-gated function `0x0004B774`
calls paired sampler `0x00035F5C` at `0x0004B8C0` with selectors
`0x07` and `0x13`, which select `ADDR7` and `ADDR19`. The `ADDR7`
result returns through `SP+4`. Its right-aligned value contributes to
the accumulator at `0x0004B922`.
