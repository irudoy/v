# SH7059 rev-limit fuel inhibit

The stock rev-limit predicate calculates separate activation and release
thresholds. Each threshold is the unsigned minimum of its scalar cap and
the curve value indexed by the oil-thermistor snapshot. The predicate uses
engine speed to update the armed and active states and returns the active
state to the fuel-inhibit coordinator.

| Stock operation | 1ME3B | 1EK7A |
|---|---|---|
| Oil-thermistor snapshot | `0xFFFE80E5` | `0xFFFE8109` |
| Engine speed | `0xFFFE819E` | `0xFFFE81C4` |
| Activation and release cap pair | `0x00009266` | `0x000093A6` |
| Activation and release curve pair | `0x000172B6` | `0x00017D1E` |
| Arm delay and countdown | `0x00008B40`, `0xFFFE94E2` | `0x00008BBF`, `0xFFFE94EF` |
| Predicate and cap comparison | `0x0007B1A0`, `0x0007B1CE..0x0007B1E6` | `0x0007C890`, `0x0007C8BE..0x0007C8D6` |
| Armed and active state | `0xFFFE948A`, bits 2 and 3 | `0xFFFE9497`, bits 6 and 7 |
| Coordinator and predicate call | `0x0007A740`, `0x0007A8FE` | `0x0007BE28`, `0x0007BFF0` |
| Final mask and store | `0xFFFE92B0`, `0x0007AD86` | `0xFFFE92AC`, `0x0007C454` |

The arm transition loads the calibrated delay. The already-armed path sets
active when the countdown reaches zero. The release comparison clears the
active request. The instruction ranges from `0x0007B1EC` through
`0x0007B250` on 1ME3B and `0x0007C8DC` through `0x0007C940` on 1EK7A bind
these transitions to the layout-specific state bits.

The coordinator adds the rev-limit request to its other inputs and stores
the result after applying the six-bit mask. The 1EK7A coordinator also has
a priority replacement path. A rev-limit request contributes to the final
mask. The selected arbitration path determines the actual value on a given
invocation. The verified path ends at the software mask.
