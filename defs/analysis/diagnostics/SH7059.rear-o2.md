# SH7059 rear oxygen monitor conditions

The bank argument is zero for bank 1 and one for bank 2. Packed DTCs identify
the output code. The local index identifies the specific record and its
runtime state.

## Separate P0139 and P0159 monitor

The rear oxygen coordinator calls the separate response monitor for both
banks. The monitor uses the group-87 bank enables, its own phase and count
qualification, and local indices 319 and 320.

The monitor requires direct mask `0x02` for bank 1 or `0x01` for bank 2. Both
bits are clear in both stock bytes. The upstream bypass bit is clear, so the
configuration contributes an inhibit at entry. The final report and
complementary state-update branches also repeat the direct bank test. Mode 07
uses this same ROM group byte through its own selector-based publication
filter.

The per-bank state machine requires the operating-state readiness bit and
checks the `0x60` mask in selected DTC runtime-record bytes. The bank
readiness checks are inlined on 1ME3B. On 1EK7A the selected bank also uses
helper `00028d8a` and requires its return to be zero. Operating range and
elapsed-state latches are additional gates.

The phase-zero transition requires the captured per-bank byte from `fffe80f4 +

state updater clears bit 0 of runtime record byte 2. This call remains behind
the same disabled bank test.

## Primary response, low voltage and high voltage

The primary monitor at `000d40ba` / `000da182` takes the bank selector and
checks the corresponding response and voltage metrics.

| Criterion and selected record | 1ME3B | 1EK7A |
| --- | --- | --- |
| Older P0139 / P0159, either response byte below the floor | `fffe976f + bank` and `fffe9771 + bank`, `ROM8[000084ba] = 0`; call sites `000d41da` / `000d41ea`, indices 161 / 162 | `fffe979b + bank` and `fffe979d + bank`, `ROM8[000084e9] = 0`; call sites `000da2d2` / `000da2e2`, indices 162 / 163 |
| P0137 / P0157, unsigned low metric < `0x4e` | `fffe97b2 + bank`, `ROM8[000089f0]`; calls `000d4350` / `000d4366`, indices 165 / 166 | `fffe97ea + bank`, `ROM8[00008a62]`; calls `000da446` / `000da4b6`, indices 166 / 167 |
| Primary P0138 / P0158, unsigned high metric >= `0x12` | `fffe97b0 + bank`, `ROM8[000089ef]`; calls `000d44fe` / `000d4514`, indices 163 / 164 | `fffe97e8 + bank`, `ROM8[00008a61]`; calls `000da5f6` / `000da60c`, indices 164 / 165 |

The primary bank-enable byte is `0x3f` at `0001afe6` and `0001ba12`. Its bank
1 / bank 2 masks are `0x80 / 0x40` for response, `0x08 / 0x04` for low
voltage, and `0x20 / 0x10` for high voltage. The older response comparisons
cannot pass because each input is unsigned and the threshold is zero. Both low
and high bank enables are set in each stock ROM.

Low and high each require two separate per-bank runtime inhibit bits to be
clear. A bank bit is selected by mask `1 << bank`. The coolant branch compares
an unsigned byte with stock floor zero, so the colder branch is unavailable.
The remaining path reads configuration byte `0xe9`; bit `0x40` is set,
requiring the current bank qualification bit before the report call. Failing
that part of the gate stores a separate deferred bank flag.

| --- | --- | --- |

| High inhibit byte pair | `fffea690`, `fffea669` | `fffea92b`, `fffea8a1` |
| Coolant byte and ROM floor | `fffe8070`, `00008bba` | `fffe8094`, `00008c37` |

| Qualification stores and subsequent primary monitor calls | `000d4d76`, `000d4d8e` in `000d48aa` | `000db002`, `000db020` in `000da996` |

The bank qualification writer requires selected readiness bits and either a
byte threshold or a comparison of a 16-bit value shifted left by eleven with a
32-bit accumulated metric. The ordinary per-bank coordinator also calls the
primary monitor at `000d3b02` or `000d9c3c`. The primary path stays available
to qualifying stock data.

The initializers at `000d343a..000d3440` and `000d947c..000d9482` write zero
to the low and response bytes and `0xff` to the high byte. The primary
monitor, its complementary evaluator, and the qualifying wrapper consume the
subsequent metric bytes or record their extrema.

## Secondary P0138 and P0158

The secondary path uses the two low bits of the same `0x3f` enable byte, mask
`0x02` for bank 1 and `0x01` for bank 2. Both are set in stock. The
coordinator calls the secondary routine for bank 1. Its equivalent bank 2
report is inlined in the coordinator. The secondary runtime gate requires its
readiness state and the unsigned per-bank input at `fffe80f4 + bank` or
`fffe811a + bank` to be at least `0x78`. When readiness or the input
comparison fails, both countdowns reload from the stock value `5`.

| Secondary decision input | 1ME3B | 1EK7A |
| --- | --- | --- |
| Runtime readiness bit | `fffeb9a7 & 0x40` | `fffebd3d & 0x01` |
| Unsigned input floor | `000089da = 0x78` | `00008a4b = 0x78` |
| Channel A arm and one-time pre-delay value | `fffeb621`, bank-indexed byte at `fffebaa2`; `0000887e = 0x78` | `fffeb977`, bank-indexed byte at `fffebe49`; `000088e6 = 0x78` |
| Channel B readiness flags | `fffe9c2e` | `fffe9cda` |
| Bank-indexed A and B countdown bases and reload | `fffebad9`, `fffebadb`; `00008ae3 = 5` | `fffebe80`, `fffebe82`; `00008b5c = 5` |
| Bank 1 routine, report call, and index | `000d4652`, `000d4834`, 167 | `000da7b0`, `000da920`, 168 |
| Bank 2 report call and index in the coordinator | `000d2b2c`, 168 | `000d8640`, 169 |

Channel A can qualify when the bank arm bit has been captured, its pre-delay
has expired, and its countdown is zero. Channel B can qualify when the bank
readiness flag is present and its countdown is zero. Either channel is
sufficient for the secondary report. A missing per-channel condition reloads
the affected countdown. The routine retains the smaller countdown as a local
minimum and, on first report, captures the raw input byte and sets the
corresponding bank latch.

## Open evidence

The normal-operation producers and physical scale of `fffe80f4` / `fffe811a`
and the primary metric bytes remain unresolved. Individual runtime inhibit
writers and the decrement routine for the secondary countdowns also retain
open bindings.
