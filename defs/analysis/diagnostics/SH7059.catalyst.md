# SH7059 catalyst monitor decision paths

The primary and secondary catalyst routines use the same two DTC records
on 1ME3B and 1EK7A. They make independent decisions before entering the
common dispatcher at `000c38f8` or `000c7990`, respectively. The runtime
record marker at `000d83ac` or `000deb60` records activity at `fffec092`
or `fffec4ee`.

| DTC | Record index | 1ME3B descriptor and attribute | 1EK7A descriptor and attribute |
| --- | ---: | --- | --- |
| P0420, bank 1 | 17 | `0001c024`, `00017a42 = 00a0` | `0001ca64`, `00018450 = 00a0` |
| P0430, bank 2 | 18 | `0001c030`, `00017a44 = 00a0` | `0001ca70`, `00018452 = 00a0` |

The descriptors use group 6 and selectors 6 and 5, respectively. The
Mode 07 group bytes `0001afba` and `0001b9e6` are both `0xe0`.
The two selectors and the `0x0080` attribute test admit both records
to service selection. The runtime status must also satisfy the selected
service response. See [Native diagnostic monitor paths](SH7059.native-monitors.md).

Both tasks load the coordinator address from their local ROM literal,
call it through R2 and execute a NOP in the delay slot.

The common caller uses group-6 mask `0x40` for bank 1 and mask `0x20`
for bank 2. Both bits are set in stock. Bank 2 also requires mask `0x04`
clear in its separate option byte. The caller checks `00008a65 = 09` at
`000f669e` on 1ME3B and `00008adc = 09` at `0010a38c` on 1EK7A. Both
banks proceed in stock. The caller runs the primary evaluator before the
secondary evaluator for each bank.

## Primary result decision

The primary result handler first intersects the current bank mask with the
comparison-result byte. If the bit is set, bank selector zero selects
P0420 and bank selector one selects P0430. Full DTC registration requires
configuration mask `0x10` clear. Both exact stock values are `0x53`, so
this result handler takes the local bookkeeping branch for a qualifying
result. It updates the selected bank's local flags, snapshot and counter.

| Current bank selector | `ffff055b` at `000f4230` | `ffff1a03` at `00107ee8` |

| P0420 full reporter | `000f423e` | `00107ef6` |
| P0430 full reporter | `000f4306` | `00107fbe` |

The primary evaluator forms a bank number by shifting its unsigned
selection byte right by one. It writes the bank number and a separate
mask of `bank + 1`. Configuration bits `0x80` and `0x04` are clear in
stock. The former enables entry to the evaluator and the latter selects
the path through the comparison and result handler.

The evaluator checks the selected bank's completion and hold state before
contributing to a time-gated accumulation. Depending on per-bank source
flags, the contribution is zero, the nonnegative value of the second
source, or the difference of the separately nonnegative first and second
sources. The evaluator stores the contribution, accumulates it and advances
an unsigned 16-bit sample count. At the stock sample floor of 70, it
divides the accumulated value by the sample count, multiplies by the raw
bank coefficient and applies the fixed-point scale. The published metric
is capped at `0xff`. For quotient `q` and unsigned coefficient `k`, the
scale uses `v = (q * k) >> 8` and `metric = min(0xff, (v * 0x51eb851f) >> 35)`.

the common record-state helper for a clear result bit. The stock
bookkeeping branch of the primary result handler instead sets the hold
bit corresponding to a qualifying result. This hold bit admits the bank

The L0-access index identifies stores to the first input in `00033140`,
`00038fe0` and `0008a5de` on 1ME3B, and in `00033e64`, `00039f5c` and
`0008bfbe` on 1EK7A. The second input has indexed stores in `0008a544`
and `0008f924` on 1ME3B. The input calculation and second-input writer
on 1EK7A remain open.

## Secondary result decision

The secondary evaluator admits the bank if the primary hold bit is set
or option mask `0x80` is set, and the completion bit is clear. Stock option
`0x53` clears `0x80`, so admission uses the primary hold bit. When the
secondary enable bit is set, the evaluator refreshes the bank's runtime
threshold by looking up an unsigned input. It then calls the result
handler with the same bank number.

The result handler tests `bank + 1` against three state bytes. A set
override bit selects the state-service branch. With that bit clear and
the enable bit clear, a set persistence bit and a working byte at or above
the stock persistence threshold select the state-service branch. The
other combinations with enable clear return. With enable set, a working
byte at or above the bank's runtime threshold selects state service.
When the working byte is below that threshold, a set persistence bit
requires it also to be below the stock persistence threshold before full
registration. The full reporter records the bank's index and updates its
local snapshots and counters.

and the bank reset publish a threshold of 50 across the unsigned input
range. The enabled full-report path therefore requires a working byte
below 50 on both layouts, which also satisfies their stock persistence
thresholds.

### Secondary accumulation and enable state

The accumulator accepts a sample when both sampling flags contain the
bank mask. It adds a scaled input byte to a saturating unsigned 16-bit
sum and increments a saturating unsigned 8-bit count. The published
working byte is the sum divided by the count, capped at `0xff`.
On 1EK7A the sum contribution has an additional table-derived weight.
That lookup uses `fffe805a` at `00108cac` and the axis/table pair
`000166cc` / `000173d4`. The stock bank coefficients are `0xa4` on
1ME3B and `0xa0` on 1EK7A.

The enable helper writes the bank's enable bit when the ready bit is set
and the sample count is at least 10. It writes the persistence bit when
the same ready bit is set and the sample count is at least 4. Under
those stock floors, enable implies persistence. A full report therefore
requires the published working byte to be below both the runtime and
stock persistence thresholds, in addition to an admitted, enabled and
non-overridden bank.

### Secondary sample qualification and override

The first sampling gate requires a per-bank dwell count of at least five,
a clear bank inhibit bit, and differing bits in the two source bitmaps.
The second gate checks operating windows and bank readiness. Stock option
`0x09` selects the per-bank readiness branch. The ready publisher requires
the second gate, reloads a stock countdown of `0x64`, and compares its local
count against a stock floor of zero. It can publish ready in the same call
that observes the second gate, including at a local count of zero.

With the same stock option, the override qualifier requires the selected
bank's enable condition and one of its two qualifying conditions. It counts
periodic `0x40` ticks while the two first-gate source bits agree and resets
the count when its prerequisites fail. The saturating byte must reach the
stock floor `0xff` before it sets the override bit. The report handler
services existing diagnostic state while the override bit is set. The bank
reset clears both sampling bits, ready and override, then reloads the
runtime threshold.

### Secondary sample and override comparator

The differential sampling gate compares the selected bank's live comparator bit with its periodic snapshot. It admits a differential sample when the bits differ, the per-bank dwell count reaches five, and the bank inhibit bit is clear. The override qualifier compares the same two bits for equality. Stock option `0x09` selects per-bank prerequisites. When those prerequisites hold and the bits agree, the override qualifier increments a saturating bank byte on `ffff8023 & 0x40` ticks. Disagreement or loss of prerequisites clears the count. At the stock floor of 255 the qualifier sets the report override bit.

All three layouts use the same comparator calculation. The stock
per-bank prerequisites are a set bank bit in map A and a set bank bit in at
least one of maps B and C. The first qualified update seeds the Q8 filter
from the sample, clears the live bit, and marks the filter initialized.
Subsequent qualified updates filter the unsigned bank byte, compare the
filter high byte with the held threshold, and set the bit for
`high_byte >= held_threshold`. A set selects the next lower threshold,
and a clear selects the next upper threshold. The stock filter coefficient
is 1, so the Q8 state update is
`floor((127 * previous + 256 * sample) / 128)`. If the computed state stays
at the previous value while below the input in Q8 units, the routine
increments it by one. The ROM thresholds are 43/48 with the map C bank
bit clear and 18/76 with it set, in lower/upper order.

#### C dwell and report override

The rear-oxygen qualification routine produces a local operating bit for
the selected bank. While that bit is set it increments a saturating
unsigned byte on `ffff8023 & 0x40` ticks, then compares the byte against a
stock floor of five. Loss of operating qualification clears the counter
and the dwell-qualified bit. The routine sets C if the new dwell-qualified
bit is set and the secondary report override is clear. Otherwise it clears
C. The other direct C writers listed above remove the selected mask. The
1ND coordinator issues individual clear operations for banks 1 and 2.
