# SH7059 EVAP monitor decision paths

The 1ME3B and 1EK7A stock images use separate descriptors for the two purge
circuit paths and the two very-small-leak paths. The local EVAP decisions,
runtime record service, and external diagnostic response each have their
own gates. All seven records below have stock attribute `0x00a0` on their
own image. Bit 7 permits eligibility at the SCI1 Mode 03 and 07 attribute
check. The runtime status still governs selection for a response.

| Record | 1ME3B index, descriptor, attribute word | 1EK7A index, descriptor, attribute word |
| --- | --- | --- |
| P0443, primary purge circuit | 47, `0001c18c`, `00017aa6` | 48, `0001cbd8`, `000184bc` |
| P0443, alternate purge circuit | 24, `0001c078`, `00017aa8` | 24, `0001cab8`, `000184be` |
| P0441, purge flow | 203, `0001c8dc`, `00017ab2` | 203, `0001d31c`, `000184c8` |
| P0442, small leak | 207, `0001c90c`, `00017aba` | 207, `0001d34c`, `000184d0` |
| P0455, gross leak | 49, `0001c1a4`, `00017ad4` | 50, `0001cbf0`, `000184ea` |
| P0456, first very-small-leak record | 205, `0001c8f4`, `00017ac0` | 205, `0001d334`, `000184d6` |
| P0456, alternate very-small-leak record | 218, `0001c990`, `00017a98` | 218, `0001d3d0`, `000184ae` |

The Mode 07 group filter excludes all seven records in both images. The
group bytes, selectors and service handlers are described in
[Native diagnostic monitor paths](SH7059.native-monitors.md#evap-and-rear-o2-publication-gates).

## Purge circuit and flow gates

The purge coordinator invokes the primary circuit decision only
when the configuration mask `0x04` is set. In that branch it calls a
separate evaluator. Its result byte uses mask `0x40` for the full reporter
and mask `0x20` for the alternate state-service call. The stock
configuration byte is zero on both images and skips the evaluator and both
consumers. The coordinator still calls the separate index-24 evaluator.

| Primary circuit stage | 1ME3B | 1EK7A |
| --- | --- | --- |
| Coordinator | `001002dc` | `00114290` |
| Stock configuration and bypass | `0001afc3 = 00` at `00100634..00100638` | `0001b9ef = 00` at `001145bc..001145c0` |
| Local evaluator call and entry | `0010063c` calls `001017b8` | `001145c4` calls `001157e4` |
| Result byte and full report | `fffe9472` at `00100644`, report at `0010067a` | `fffe947e` at `001145cc`, report at `00114602` |
| Alternate evaluator call | `00100692` calls `00101b7a` | `0011461a` calls `00115ba6` |

The stock scheduler table selects the diagnostic task on both layouts.
On 1EK7A `000c4928` loads `00114290` from `000c4b48`, and `000c492a`
calls that address with a `nop` in the delay slot. The 1EK7A task entry
and call are present in the stock instruction listing. The task entry
is absent from L0.

| Scheduled diagnostic task | 1ME3B | 1EK7A |
| --- | --- | --- |
| Scheduler table slot and task entry | `000222c8` selects `000c0040` | `0002235c` selects `000c4884` |
| Coordinator call | `000c00e0` calls `001002dc` | `000c492a` calls `00114290` |

The alternate P0443 evaluator tests mask `0x02` at `0001afbd` or
`0001b9e9`. The stock byte is `0x20` on both images, so the function
returns before its capture and result branches. Behind that gate it
captures a reference word and shifts a ten-word history at a sample-count
threshold of ten.

| Alternate circuit stage | 1ME3B | 1EK7A |
| --- | --- | --- |
| Configuration load | `00101b8e` | `00115bba` |
| Word source and reference read | `fffeab40` at `00102116` | `fffeae70` at `00116140` |
| History sample read | `00102202` | `0011622a` |
| Full reporter when qualified | `0010235c`, index 24 | `00116382`, index 24 |

The two publishers select the direct input word or a filtered sample.
For `delta = sample - 0x1900`, they return zero for negative `delta`
and otherwise write the unsigned 16-bit saturation of
`(delta * 0x247c * 0xc7ce0c7d) >> 45`. The stock filter coefficient is
zero on both layouts. When the filter branch is selected, the stored
sample stays unchanged unless it is below the input word. In that case
the filter advances it by one.

| --- | --- | --- |

| Previous filtered sample | `fffeab6e` | `fffeae9e` |

The 1EK7A publisher entry and store are present in the stock instruction
listing. The publisher entry is absent from L0. The upstream electrical
channels and physical scale remain unresolved on both layouts.

P0441 is behind configuration mask `0x02` at `0001afec` or `0001ba18`.
The exact stock byte is zero on both images. The disabled case bypasses
the purge-flow evaluator at `00102cc4` or `00116ce8` and its result handling.
The active branch uses the result flag at `fffe9493` mask `0x01` on 1ME3B
or `fffe949f` mask `0x20` on 1EK7A. Its full reporter sites are `001007cc`
and `00114738`.

## Primary leak report readiness

The leak decisions enter the full P0442, P0455 and index-205 P0456 reporter
only after the environmental comparisons. Each report requires two
unsigned bytes in independently calibrated windows. In both stock images,
each window requires `0xff <= input < 0x00`. Either window independently
prevents this full-report path from succeeding.

### P0442 and index-205 P0456 record-state service

The P0442 evaluator separately compares the unsigned high byte of the
leak working word with `0xff`. Below that threshold it calls the shared
record-state service with index 207, then records the saturated sample,
threshold, selected statistics and counter updates. At `0xff` it
proceeds to the environmental comparisons for the full reporter. The
gross-leak function can reset the working word to zero. It also calls
the estimator that computes the working word before the P0442 decision.

| Direct zero store | `0010a154` | `0011e18a` |
| Unsigned high-byte threshold | `00008767 = ff` at `00108f4c` | `000087c7 = ff` at `0011cf94` |

#### Leak working-word estimator

The gross-leak function passes the working-word address in R6. The
estimator keeps the pointer in R13, computes the result and stores one
word through R13. The caller then loads the written word and copies it
to a diagnostic snapshot. On both layouts the estimator derives a
reference word through a ROM interpolation. The input for the reference
and the compensated word passed in R5 use the same interpolation table
and distinct inputs. The estimator produces a zero intermediate when
the reference is at or below the compensated word. For a positive
difference it applies fixed-point scaling and division. A zero divisor
or an out-of-range quotient selects the intermediate value `0xffff`.
The final write saturates `(intermediate * factor1 * factor2) >> 14`
to `0xffff`, with both factors taken from byte-valued ROM lookups.

#### First very-small-leak record

The same record-state service receives index 205 at `001096e6` or
`0011d736`. Those calls precede the environmental gates for the full
report. They require the leak working word's high byte below the stock
threshold `0xff` at `0000876b` or `000087cb`, and the local state at
`fffeb9a5` mask `0x80` or `fffebd3b` mask `0x04`. The state service clears
bit 0 of byte 2 in its index-specific runtime records. When the tested
active flags are clear, it also sets bit 2 of byte 1 and performs the
corresponding pending-state cleanup. The full reporter uses separate
dispatcher and marker routines.

### Alternate P0456 decision

Index 218 has its own evaluator at `0010c2e4` or `0012033c`. The local
reporting body requires configuration mask `0x02` at `0001afee` or
`0001ba1a`. The exact stock byte is `0xf9`, and each body is bypassed.
The function writes its delta comparison state before that bypass. The
stock-selected comparison uses the current unsigned word minus five times
the captured byte, plus a signed offset of zero. It compares the result
against 40. The corresponding state masks are `0x80` on 1ME3B and `0x20`
on 1EK7A.

## DTC dispatch and registration

The conditional full-report paths pass their descriptor indices to the
shared dispatcher at `000c38f8` or `000c7990`. The runtime record marker
at `000d83ac` or `000deb60` writes the report-activity byte at `fffec092`
or `fffec4ee`, respectively.

The common DTC dispatcher independently checks mask `0x40`
in `0000888a` or `000088f6`. Both stock bytes are `0x34`, so a delivered
index 218 retains its identity. With that mask set, the dispatcher selects
the P0455 index if its status byte 2 contains `0x60` bits, otherwise it
selects index 207 when the P0442 record contains those bits or index 205
when neither record qualifies. This mapping is separate from the local
reporting body and the service publication filter.
