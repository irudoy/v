# Intake CVTC diagnostic decisions on 1ME3B and 1EK7A

The primary diagnostic coordinator computes the per-bank position error
and calls the timing and solenoid-circuit qualifiers. A separate timing
monitor evaluates capture-derived phase bytes against stock references.
Both timing paths can report P0011 and P0021. The circuit qualifiers
feed P0075 and P0081 through the primary report dispatcher.

Each centered error byte is `clamp(target_word - measured_word + 128,
0, 255)` using unsigned word operands. The diagnostic timing qualifier
checks both the error window and the runtime qualification count. In the
window test the stock lower and upper deviations are both `0x1a`
(`00008895..00008896` / `00008903..00008904`). A separate branch tests for
a count greater than the runtime limit at `fffe839f` / `fffe83c3`.
Prior DTC state, bank state, and the `0x8000` target sentinel participate
in readiness. The measured words also have initialization stores in
`001198b0` / `00138240`.

The staged circuit qualifier compares the per-bank count against
`0x0a` and `0x64`, from `00008a44..00008a45` / `00008ab8..00008ab9`.
It sets the record-marker flag at count 10 and the full-report flag at
count 100 once its runtime conditions qualify. The alternate circuit
qualifier can set both at count 100 under its own readiness conditions.
The shared status byte at `fffe9759` / `fffe9785` and bank-local bytes
`fffe9a1e..fffe9a1f` / `fffe9a64..fffe9a65` participate in the circuit
conditions. The values are counts of qualifying passes.

The direct marker calls bypass the full reporter. Each timing call also
copies the selected three-byte runtime record to the timing snapshot.
The bank 1 snapshot begins at `fffed873` / `fffedea2`, followed by bank 2.
The circuit calls skip this snapshot.

## Periodic publication of the measured phase words

| Operation | 1ME3B | 1EK7A |
| --- | --- | --- |
| Periodic task pointer | `ROM32[00022258] = 00119b00` | `ROM32[000222ec] = 00138540` |
| Bank 1 capture-word store, IMI1F | `0003115c` to `fffe9296` | `00031e84` to `fffe9292` |
| Bank 2 capture-word store, IMI1E | `00030e58` to `fffe9298` | `00031b80` to `fffe9294` |
| Bank 1 / bank 2 reference words | `fffebfd2` / `fffebfd4` | `fffec3be` / `fffec3c0` |
| Normal reference update call and writer | `00119e46` calls `0011ad9c` | `001388ca` calls `0013994c` |
| Phase-update admission byte and stock task load | `fffe81bc` at `00119b40` | `fffe81e0` at `00138584` |
| Bank 1 call, phase publisher and measured-word store | `00119b1e` to `0011aa10`, store `0011aab2` | `00138560` to `0013953e`, store `001395e4` |
| Bank 2 measured-word store in the periodic task | `00119bd0` | `0013860c` |
| Bank 2 live-angle byte store in the periodic task | `00119be4` to `fffe942e` | `00138622` to `fffe943a` |

The task passes bank index zero to the bank 1 publisher and handles bank 2
inline. Both phase update paths require a nonzero admission byte. A zero
capture word selects the neutral intermediate `0x8000`. With a nonzero
capture the intermediate is `0x8000 + trunc0((reference - capture) / 2)`
from two unsigned input words. The measured word is
`0x8000 + trunc0((intermediate - 0x8000) / 128)`. Each `trunc0` rounds
toward zero. The 1EK7A task also stores the intermediate before scaling at
`ffff12cc` / `ffff12ce`.

The same computation emits the existing live-angle byte as
`clamp(measured_word - 0x7f80, 0, 255)`. Its `0.5 * x - 64` conversion
gives `0.5 * (measured_word - 0x8000)` degrees crank angle over the
unsaturated live-byte range. The RAM publishers and ROM arithmetic
establish this encoding. The physical source scale of the capture and
the upstream admission and reference update conditions require their own
evidence. The 1EK7A periodic entry and its bank 2 instructions are bound
by the stock task pointer and its prepared function body.

## Independent timing decision

| Role | 1ME3B | 1EK7A |
| --- | --- | --- |
| Timing monitor | `000e5e54` | `000f0608` |
| Raw phase samples, bank 1 / bank 2 | `fffe9288` / `fffe9289` | `fffe9284` / `fffe9285` |
| Bank 1 IMI1F / bank 2 IMI1E capture entries | `00030eac` / `00030b90` | `00031bd4` / `000318b8` |
| Bank 1 IMI1F / bank 2 IMI1E capture stores | `00031164` / `00030e60` | `00031e8c` / `00031b88` |
| Stock references, both `0xb4` | `00008313` / `00008316` | `00008326` / `00008327` |
| Centered error bytes, bank 1 / bank 2 | `fffe8688` / `fffe8689` | `fffe86a7` / `fffe86a8` |
| Common readiness byte | `fffe80f0` | `fffe8116` |
| Full P0011 / P0021 calls | `000e619e` / `000e6276` | `000f098c` / `000f0a92` |

The secondary path computes `clamp(unsigned_sample - unsigned_reference,
-128, 127) + 128`. The two capture interrupt paths publish the bank
samples. The bank 1 path stores the high byte of a clamped capture-derived
word. On 1ME3B the `bt/s` at `0003100a` enters the continuation at
`00031054` after the literal pool. A separate branch at `00031022` joins
the continuation at `00031076`. The shared selected target word is
checked against `0x8000` at qualification. Its value is separate from the
stock references used for the subtraction.

The monitor qualifies its operating state with `0x7d < readiness <= 0xc8`
and per-scenario state and inhibit bits. The two scenarios each evaluate
both banks. The stock group byte `0xfc` at `0001afeb` / `0001ba17` enables
bank 1 via bit 3 and bank 2 via bit 2. An error strictly outside the
stock `[-26, 26]` window can advance the per-bank decision. Independent
marker and full-report countdowns use a stock reload of `0x1e` and can
take their respective branches at zero.
