# Native diagnostic monitor paths on 1ME3B and 1EK7A

The stock monitoring routines report a local descriptor index to the DTC
reporter. The reporter and record marker form the common registration
path on 1ME3B and 1EK7A. The monitor inputs and report sites below
identify the per-layout registrations.

## Shared DTC path

| Role | 1ME3B | 1EK7A |
| --- | --- | --- |
| DTC reporter | `000c38f8` | `000c7990` |
| Dispatch to the runtime record marker | `000c3964` | `000c79fc` |
| Runtime record marker | `000d83ac` | `000deb60` |
| Stock descriptor table base | `0001bf58` | `0001c998` |
| Descriptor stride and flag selection | `000c3978..000c3988` | `000c7a10..000c7a1e` |

The report input is the record index in R4. The reporter delegates the
local index, and independently reads descriptor byte 8 at the original
index to select record-class handling. For the special index 218, the
rewrite branch tests configuration bit 6. Both code paths obtain the
original ROM byte `34` with this bit clear. The normal stock
delegation retains the input index. Local record-marker calls and
descriptor-table reads are the machine evidence for shared placement
in `dtc_manager/block`.

Each report-site argument resolves to a local ROM descriptor through the
stock table geometry. For example, P0443 in the first purge path uses
`0001c18c` on 1ME3B and `0001cbd8` on 1EK7A, while the alternate path
enters separate group-9 records `0001c078` and `0001cab8`. Per-bank
duplicates have independent bindings. Descriptor and attribute
records establish the identities of the report sites.

The report sites and exact descriptor records establish firmware
dispatch and runtime record marking. Individual sensor transfer
functions and service-response eligibility have separate evidence.

## Rear oxygen decision inputs

Both primary rear O2 monitors select the same form of bank-specific raw
criteria. The code comparisons and stock calibration values define which
criterion can enter the respective report branch:

| Criterion in this monitor | 1ME3B local comparison and inputs | 1EK7A local comparison and inputs |
| --- | --- | --- |
| Either of two unsigned response metrics below the response floor | `000d417e..000d419a`; byte lane pairs from bases `fffe976f`, `fffe9771`; ROM `000084ba = 00` | `000da242..000da25e`; byte lane pairs from bases `fffe979b`, `fffe979d`; ROM `000084e9 = 00` |
| Unsigned low-voltage metric below the threshold | `000d42fe..000d430e`; RAM pair at `fffe97b2`; ROM `000089f0 = 4e` | `000da3f2..000da402`; RAM pair at `fffe97ea`; ROM `00008a62 = 4e` |
| Unsigned high-voltage metric at or above the threshold | `000d44b4..000d44c4`; RAM pair at `fffe97b0`; ROM `000089ef = 12` | `000da5aa..000da5ba`; RAM pair at `fffe97e8`; ROM `00008a61 = 12` |
| Selected coolant comparison before final branch execution | `fffe8070` against ROM `00008bba = 00` | `fffe8094` against ROM `00008c37 = 00` |

The first criterion cannot pass with the stock zero floor and unsigned
inputs. That finding is limited to these two local P0139/P0159 branches.
The low/high voltage branches additionally inspect bank-specific enable
and state bits. The physical voltage mapping of the raw metrics remains
unresolved.

Exact descriptors 10 through 16 identify P0306 through P0300 in both
images. The shared misfire binding covers result selection and report
calls. The upstream crank metric and monitor readiness retain their
separate evidence boundary.

The atlas chain `native_dtc_report_sh7059/chain` shows five native
monitor-to-marker paths and terminates at the activity byte. The write
stores one on each non-sentinel indexed record report. Other native
routines access the same byte, so the activity byte describes firmware
report processing, with final external diagnostic publication and
retention outside the bound record path.

The stock decoder verifies all listed record indices in their own image.
L0 calls connect every monitor to `000c38f8` (1ME3B) or `000c7990`
(1EK7A). The report spans contain the R4 record argument and the
branch or call.

The MAF path reads the selected input in the `fffe8018` pair on
1ME3B and the `fffe801a` pair on 1EK7A. The first low result
comparison reads the sensor word and the threshold word `0x0050`,
at `000c9796..000c97a0` / `000ce944..000ce94e`. The paired
threshold arrays start at `00008e42` / `00008ede`. The monitored
operands have distinct addresses from the published MAF words. The
relationship between the monitored words, published words, and physical
voltage remains unresolved.

APP1 reads `fffe96ce` and `fffe96f8` respectively and compares the
unsigned snapshot to stock `0x003c`. Its entry spans start at
`000fa65c` and `0010e734`. Both reads use the `app1/ram` binding. The
two throttle range monitors begin by
comparing inputs `fffe97ea` / `fffe9824` and `fffe97e2` /
`fffe981c` with unsigned bounds `0x003c` and `0x03c4`. Diagnostic
flags and additional gates still determine publication. The CVTC rows
establish the condition-to-DTC dispatch sites, with the complete
error model and its mechanical angle units outside the traced slice.

## MAF range/performance

The diagnostic tasks selected by `000222c8` (1ME3B) and `0002235c`
(1EK7A) call their respective MAF coordinators `000c96fc` and `000ce8ac`
at `000c007a` and `000c48be`. P0101 and P010B use separate range results
from the MAF circuit reports.

On 1ME3B, stock `ROM8[0001afe3] = 0x0f` enables the range branch when the
diagnostic readiness gates hold. The coordinator calls `000f2b54` at
`000c9a98` to qualify the high and low ratio decisions using the stock
timer thresholds of 1000, 50 and 500 enabled invocations. `000ca3b0`
requires the absolute difference between unsigned sensor words `fffe8018`
and `fffe801a` to exceed 60 raw counts. It produces report bits 3 and 2 in
`fffeb981`. The coordinator calls report index 177 (P0101) at `000c9c6e`
and index 7 (P010B) at `000c9c8e` when the respective bit is set.

On 1EK7A, the coordinator reaches `00105ab0` at `000ced2a`. The model
reads `ROM8[0001ba44]` at `00105b70`. Both tested configuration bits
are clear in stock, and `00105b8c` skips the ratio calculation, qualifier
`001060a0` and its timers. The result reader still tests existing state
bytes. P0101 (index 346) uses the runtime marker at `00106018` and the
full reporter at `0010604e`. P010B (index 347) uses those paths at
`00106008` and `00106028`. A separate state service receives the same
indices at `00105ff8` and `00105fe8`, respectively. The scheduled stock
model generates no new range result from cleared state.

The skipped qualifier uses scalar and curve bounds of zero and
`65535 / 256` in the stock calibration and 500 enabled invocations per
condition. The original attribute `0x0670` leaves bit 7 clear on these
descriptors, excluding them at the Mode 03 and Mode 07 attribute gate.

The mode handlers test runtime record state as well as the ROM attribute
and route eligible packed code bytes to the shared append routine.
That routine reads the response length and stores R4's low byte in the
response buffer before incrementing the length. The layout-specific
length cells are `fffeb6b8` and `fffeba18`. Register state and
descriptor evidence are distinct from the DTC report-activity byte.

## Stock OBD response transmission on SCI1

On 1ME3B and 1EK7A, the Mode 03 and Mode 07 handlers tail-call a common
finalizer. It pads the response with zero DTC pairs up to three pairs,
sets the OBD session phase to 4, and clears bit 0 of the adjacent flags byte.
The dispatcher stages the response with header `48 6b 10`, service byte
`mode + 0x40`, and the payload. In phase 4, when the transmit gate byte
is zero, it reads the staged bytes in order, advances the cursor, and
accumulates their sum. Once the cursor reaches the response length, it sends
the low eight bits of the sum, clears the cursor and sum, and changes the
session phase.

| Stock location | 1ME3B | 1EK7A |
| --- | --- | --- |
| Mode 03 and Mode 07 tail jumps | `0003f4ce`, `00040542` | `000404b6`, `0004152a` |
| Shared finalizer and phase-4 store | `000412d0`, `00041302` | `000422bc`, `000422ee` |
| Session phase byte | `fffedfaa` | `fffee65a` |
| Dispatcher invocation in the serial service | `00036f6a` calls `0003e2c4` | `00037ee6` calls `0003f2ac` |
| Staged response base and length | `fffeb0cd`, `fffeb6b8` | `fffeb403`, `fffeba18` |
| Transmit gate, cursor, and sum | `fffebccd`, `fffedfb0`, `fffedfaf` | `fffec07c`, `fffee660`, `fffee65f` |
| Indexed response-byte load | `0003e72c` | `0003f714` |
| Staged byte and checksum calls | `0003e736`, `0003e74a` | `0003f71e`, `0003f732` |
| Byte sender and TDR1 store | `00037032`, `00037046` | `00037fae`, `00037fc2` |
| SSR1 write with TDRE bit cleared | `00037050` | `00037fcc` |
| Completion branch that sets SCR1.TEIE | `0003e782` | `0003f76a` |

The byte sender first calls `00037fb8` or `00038f34`, which clears
SCR1.RIE and SCR1.RE. The sender writes R4's low byte to SCI1 TDR1 at
`fffff00b`, then reads and writes SCI1 SSR1 at `fffff00c` with
bit 7 (TDRE) cleared. Table 15.2 and sections 15.2.6 and 15.2.7 of the
SH7059/SH7058S hardware manual define the register addresses and bits.

The traced path reaches the SCI1 registers on both layouts. The stock
cross-references at the buffer bases identify the dispatcher and the byte
append routine. A diagnostic route from these response handlers to an
HCAN transmit queue or mailbox remains unverified, as do board-level
routing and observed transmission.
