# SH7059 misfire monitor and DTC registration

The 1ME3B and 1EK7A stock ROMs schedule a window producer and a separate decision routine. The decision routine consumes the window counts and selects aggregate or cylinder-specific DTC records. Queue maintenance is a distinct, later path for already queued records.

## Event latch, interval deviation, and count producer

The scheduled wrapper calls an event-preparation routine before the count producer. The first routine ORs mask `0x80` into `ffff8038`. The producer tests both the ROM group enable and that pending bit. If admitted, it clears just the pending bit and requires a raw history-state byte of at least 13 for the input-refresh and deviation branch. The short-history path shifts the output histories and writes the `0x80` sentinel.

For successive 32-bit values `T0`, `T1`, and `T2` in address order, the producer passes `(T1 - T0) + 5 * (T1 - T2)` to the deviation helper. The reviewed count branch increments the aggregate word and the word selected by `2 * cylinder` from the same base. The flag builder below binds indices 1 through 6 to the six cylinder lanes. Separate histories and other count banks have their own admission and reset branches.

## Cylinder attribution from crank capture

The ICI0A crank-capture interrupt publishes the cylinder number for a captured
misfire interval. The periodic misfire window producer reads the published byte
and uses twice its unsigned value as the byte offset into the cylinder count
words. The event index consumed by the capture interrupt is a separate byte.

The ordinary tooth-7 path copies the phase-state byte from `GBR+0x42` to the
event-index byte. The same interrupt also writes the event index at
`000304ac` and `000311d4`, respectively. The later publication path rejects
event index zero and requires the current tooth (`GBR+0x2c`) to match the
configured end tooth.
The interval and cylinder stores occur when `ffff8031.bit7` is set. The path
publishes the interval byte, looks up the cylinder by event index and publishes
that byte, then sets `ffff8032.bit7`. The periodic wrapper's event-preparation
routine uses its own pending bit at `ffff8038.bit7`.

At the first interrupt after reset, the handler initializes the seven-byte RAM
map and sets a one-byte latch. The initialization code at
`0002f784..0002f7c5` and `000304a8..000304e9` uses the same instructions with
layout-specific literals.

Both initializers use start tooth `a` and end tooth `b`. They set bit 0 to
`!(a >= 7 && b < 7)` when `a >= b` and to `a < 7 && b >= 7` when `a < b`.
The stock values `a = b = 9` set the bit on both layouts. The 1ME3B interval coordinate
and calibration context are described in the

The maps associate input indices 1..6 with six distinct cylinder numbers.
The count access uses `count_base + 2 * cylinder`, with the aggregate word
directly at `count_base`.

### Identified cylinder from cam capture

The IMI1E and IMI1F cam-capture handlers increment separate byte counters,
saturating each at 255. In the ICI0A tooth-4 path, the cam-pattern branch
appends each count to its own eight-bit history as
`((history << 2) | min(unsigned_count, 3)) & 0xff`. The decoder selects a
history and converts a recognized pattern to cylinder 1..6. It publishes zero
for an unrecognized pattern. On tooth 7 the crank handler copies the identified
cylinder to the event index. The interval-end path uses that index to look up
the cylinder for the periodic misfire count.

## Readiness and window result flags

An early readiness branch calls the crank/cam fault-state helper and requires a zero result. It then requires mask `0x60` clear in each of four additional DTC runtime status bytes. Other branches test the operating-state enable, a readiness count of at least one, the unsigned operating-input window `0x06 <= value < 0x5a`, and a battery-voltage snapshot of at least `0x89`. These are firmware predicates on raw values.

| Fault-state helper call and zero test | `000cb2e6` -> `00027e88`, test `000cb2ea` | `000d097c` -> `000288d0`, test `000d0980` |
| Four extra DTC runtime byte-2 reads | `fffed80c`, `fffed80f`, `fffed422`, `fffed45e` | `fffede3b`, `fffede3e`, `fffeda12`, `fffeda4e` |

| Set the local aggregate bit when at least two cylinder words meet the floor | `000cc834..000cc83a` | `000d1f90..000d1f98` |

The decision path first clears the previous local result bits. It compares each cylinder word with the inclusive floor and builds the new bitmap. The associated repeat counter saturates at `0xff`. The firmware has additional aggregate-report paths, so a count of two cylinders is sufficient to set the aggregate bit in this branch. The branch that copies the highest cylinder share multiplies the maximum of the six cylinder counts by 100 and divides it by the aggregate count after that count reaches a separate runtime word threshold (`fffe9c88` or `fffe9d3c`).

The entry reset zeroes the aggregate and cylinder counter region when `fffeba65 & 0x02` is set on 1ME3B or `fffebe09 & 0x01` is set on 1EK7A. Further readiness failures clear working count and snapshot arrays. Earliest count reset stores in the decision routines are `000cb0f0` and `000d081a`. The result rebuild clears the 1ME3B local flag bits with `and.b 0x80` at `000cc7d6`. It clears the two 1EK7A local flag fields with `and.b 0xf8` at `000d1f28` and `and.b 0x0f` at `000d1f2c`.

## Aggregate and cylinder-specific registration

Each row uses the matching packed stock DTC from the 12-byte descriptor table. The local masks below refer to the result bytes, and the prior-record checks in the selector read byte 2 of the three-byte DTC runtime record.

| DTC and local index | 1ME3B local mask at `fffeb9f0` | 1EK7A local mask |
| --- | --- | --- |
| P0300, 16 | `0x01` | `fffebd91 & 0x10` |
| P0301, 15 | `0x40` | `fffebd90 & 0x04` |
| P0302, 14 | `0x20` | `fffebd90 & 0x02` |
| P0303, 13 | `0x10` | `fffebd90 & 0x01` |
| P0304, 12 | `0x08` | `fffebd91 & 0x80` |
| P0305, 11 | `0x04` | `fffebd91 & 0x40` |
| P0306, 10 | `0x02` | `fffebd91 & 0x20` |

On 1ME3B, `000cd5b0` reports index 16 for a local aggregate result, a prior aggregate runtime result (mask `0x04`), or prior cylinder flags (mask `0x04`) with no corresponding cylinder set in the local result. Otherwise the selector tail-calls the reporter for the first matching local cylinder bit, testing indices 10 through 15 in that order. Its cylinder tail jumps are `000cd774`, `000cd784`, `000cd794`, `000cd7a4`, `000cd7b4`, and `000cd7c4`. The aggregate call is `000cd7ca`.

On 1EK7A, `000d2e0e` can issue more than one report in an invocation. It tests each index in the order 16 through 10. For each index, a prior DTC runtime result under mask `0x44` suffices. The local cylinder flags qualify independently when the local aggregate bit is clear. The aggregate call and cylinder transfers are `000d2ff8`, `000d301a`, `000d303c`, `000d305e`, `000d307a`, `000d3096`, and `000d30be`.

Both report selectors dispatch to the stock DTC reporter and its record marker. The marker sets bit 7 of runtime record byte 1 and writes one to the report-activity byte. The activity bytes are `fffec092` and `fffec4ee`.

## Queue maintenance

Both queue handlers walk the configured eight slots until the `0xffff` index sentinel. The shared first-pass conditions require runtime record byte 2 mask `0x60` and runtime record byte 1 mask `0x20` clear. The next condition differs by layout.

| Queue condition | 1ME3B | 1EK7A |
| --- | --- | --- |
| Handler and caller sites | `000f1db8` from `000c29ee`, `000c2a04` | `00104b9e` from `000c6b8c`, `000c6c08` |
| Runtime status base | `fffed420` | `fffeda10` |
| Additional exclusion condition | Index matches a 32-bit entry in the 30-entry ROM list at `000250d8` (lookup `000f1e1a`, comparison `000f1e1c`, exclusion branch `000f1e90..000f1e92`) | Descriptor byte `ROM8[0001c998 + 12 * index + 8]` has bit `0x04` set (test `00104c46..00104c48`) |
| Queue flag `0x08` readiness | `fffeb9e1 & 0x80` | `fffebd7f & 0x04` |
| Compaction call, after both queue flags `0x08` and `0x04` | `000f1efe` -> `000f1bac` | `00104cb2` -> `00104978` |

The 1ME3B list contains no misfire index from 10 through 16. The 1EK7A misfire descriptors at those indices contain byte 8 value `0x40`, so bit `0x04` is clear. Each variant therefore permits these indices through its extra first-pass filter. The external attribute halfwords used by the publication path are `0x00b0` on 1ME3B and `0x00b8` on 1EK7A for these indices.

The handlers set flag `0x08` when the respective runtime readiness condition is present. The nonzero call argument authorizes flag `0x04`. On 1ME3B the first-pass branch that newly sets `0x08` advances directly to the next slot, skipping the `0x04` set for that slot during the same pass. On 1EK7A both flags may be set in one pass. Both compaction sweeps inspect slots in reverse order and remove entries whose flags already contain both bits.

## Open evidence

- The first timing input has a verified refresh writer and an exact consumer in both layouts. The capture timer's connection to these timing words, their scale and the mechanical phase of the captured edges remain open.
- The producer has additional count banks and history branches. Their relationship to engine banks and the physical calibration of the normalized deviation require independent evidence.
- The 1EK7A periodic wrapper is pinned by its entry-pointer word and verified call bytes. Its function entry is absent from the current prepared L0.
- The stock predicates establish conditional applicability. The physical detection threshold, monitor completion in vehicle operation and external DTC retention have separate evidence requirements.
