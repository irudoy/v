# SH7059 misfire monitor and DTC registration

The 1ME3B and 1EK7A stock ROMs schedule a window producer and a separate decision routine. The decision routine consumes the window counts and selects aggregate or cylinder-specific DTC records. Queue maintenance is a distinct, later path for already queued records.

They take report-selector paths at `000cc414`, `000cc798`, `000cc9f8`, `000cccce`, and `000ccf58` on 1ME3B, and `000d1b16`, `000d20bc`, `000d2210`, `000d252a`, and `000d2784` on 1EK7A.

## Event latch, interval deviation, and count producer

The scheduled wrapper calls an event-preparation routine before the count producer. The first routine ORs mask `0x80` into `ffff8038`. The producer tests both the ROM group enable and that pending bit. If admitted, it clears just the pending bit and requires a raw history-state byte of at least 13 for the input-refresh and deviation branch. The short-history path shifts the output histories and writes the `0x80` sentinel.

For successive 32-bit values `T0`, `T1`, and `T2` in address order, the producer passes `(T1 - T0) + 5 * (T1 - T2)` to the deviation helper. The reviewed count branch increments the aggregate word and the word selected by `2 * cylinder` from the same base. The flag builder below binds indices 1 through 6 to the six cylinder lanes. The separate history paths and their count banks are described below.

### Five aggregate and cylinder count banks

its base and six cylinder words at `base + 2 * cylinder`, for cylinder
numbers 1 through 6. The three event history paths share the cylinder
attribution byte (loads `000cf52c`, `000cf66a`, `000cf7b4` on 1ME3B
and `000d4d70`, `000d4eb4`, `000d4ff8` on 1EK7A).

aggregate and cylinder words independently stop at `0xffff`. The first

misfire interval. The periodic misfire window producer reads the published byte
and uses twice its unsigned value as the byte offset into the cylinder count

### Crank capture, interval history, and the three timing words

ICI0A reads the 32-bit crank capture register `ICR0A` at `fffff434`.
On the configured start tooth it saves the captured value and sets
`ffff8031.bit7`. On the configured end tooth, with that bit set, it reads
`ICR0A` again and subtracts the saved start. It negates a negative
32-bit result and publishes the resulting longword at the head of the
misfire interval history. The cylinder attribution byte is published
alongside it. The interrupt then sets `ffff8032.bit7`.

### Timing correction admission and state

The timing refresh at `000cfcb0` or `000d5518` can scale the three
interval-history inputs before the deviation calculation. Five unsigned
16-bit factors `Q[0..4]` occupy consecutive halfwords. A factor of
`0x8000` gives a unity scale.

The refresh first clears the correction-ready latch when
`ffff8031.bit7` is clear. It then requires all the conditions below.
The stock ROM enables the correction path and supplies the same factor
bounds and minimum age on both layouts.

| Condition or state | 1ME3B | 1EK7A |
|---|---|---|
| ROM enable bit 7 set | `ROM8[000087bb] = 0x80` | `ROM8[00008823] = 0x80` |
| Correction-ready latch bit 7 set | `fffeba19`, test `000cfcd2..000cfcd6` | `fffebdbc`, test `000d553a..000d553e` |
| Runtime inhibit bit 4 clear | `fffeba4d`, test `000cfcda..000cfcde` | `fffebdf1`, test `000d5542..000d5546` |
| All five factors in inclusive range `0x7eb5..0x8148` | `fffecf92`, bounds at `00009386`, `00009388` | `fffed4ac`, bounds at `000094e4`, `000094e6` |
| Local admission bit set | `fffeb9c8.bit2`, test `000cfd3a..000cfd3e` | `fffebd62.bit1`, test `000d55a2..000d55a6` |
| Unsigned correction age at least 20 | `fffecf88`, floor `ROM8[00008747] = 0x14` | `fffed4a0`, floor `ROM8[000087a6] = 0x14` |
| Output bit 2, set when correction is selected | `fffeba18`, write `000cfea8` | `fffebdbb`, write `000d5758` |

When a gate fails, the refresh copies `B[3]`, `B[8]`, and `B[9]`
and clears the output bit. There are two direct-copy blocks on each layout.
If the gates pass but the dispatch cylinder byte lies outside 1..6, the
refresh sets the output bit and preserves all three previous timing words.
The output bit therefore records path selection. Fresh corrected words
require a cylinder in the accepted range.

The factor updaters at `000cfb00` and `000d5346` also write the
correction-ready latch. The updater sets bit 7 after the counter at
`fffeacd5` or `fffeb005` reaches the stock prerequisite of 8. The branch
testing bit 3 of the same control byte used for the runtime inhibit
(`fffeba4d` or `fffebdf1`) clears that request, zeroes the correction
age, and fills all five factors with `0x8000`. The update path increments
the correction age up to 255.

### Estimating the five timing correction factors

The window producer calls the interval-ratio collector, the factor
updater, and the timing refresh in that order. The collector forms one
set of five ratios on an admitted event with cylinder attribution 6.
It compares the unsigned endpoint words `B[1]` and `B[7]` of the raw crank
interval history and clears the partial cohort when `B[1] < B[7]`.

For `B[1] >= B[7]`, it computes
`d = trunc_toward_zero(int32(B[7] - B[1]) / 6)`. The signed multiply-high
sequence uses reciprocal `0x2aaaaaab`. For factor index `j = 0..4`:

1. Form the reference `R = uint32(B[1] + (5-j) * d)` and take the measured
   interval `X = B[6-j]`. The five measured indices are 6, 5, 4, 3, and 2.
2. Shift both words right by one until `R <= 0x1ffff`. Compute the unsigned
   quotient with dividend `R << 15` and divisor `X`. The divider returns
   zero for a zero divisor.
3. Store the low 16 bits of the quotient and add that unsigned halfword
   to the 32-bit sum for index `j`.

The collector increments the cohort count after adding all five ratios.
The stock cohort length is 8. On an admitted call with the old count
already at least 8, it starts a new cohort before any further accumulation.

|---|---|---|
| Initial bit and state byte | `fffe944b.bit6` set, `fffe92b0 == 0x3f` | `fffe9457.bit6` set, `fffe92ac == 0x3f` |
| Readiness and inhibit | `fffeba68.bit5` set, `fffeba4d.bit4` clear | `fffebe0c.bit3` set, `fffebdf1.bit4` clear |
| Delay and local enable | `fffebca5 == 0`, `fffeb9a8.bit5` set | `fffec04e == 0`, `fffebd3f.bit7` set |

The factor updater requires the cohort count `N` to reach the same stock
minimum of 8. It sets the correction-ready latch and computes each
mean `M[j] = uint16(floor(sum[j] / N))`. If the correction age
is zero, it copies all five means into `Q`. Otherwise it compares the old
factors with the means and repeatedly averages the candidate with the
same old factor, rounding down at each step. The stock iteration count
is 3, which gives `Q[j] = floor((M[j] + 7 * old_Q[j]) / 8)`.

At correction age 5 or higher, any `abs(M[j] - old_Q[j]) >= 33` resets
the entire table to unity `0x8000` and clears the age. The explicit reset
request in bit 3 of `fffeba4d` or `fffebdf1` has the same table and age
effect and clears the request bit. A completed copy or blend increments
the age up to 255. On 1EK7A the zero-count guard stages five `0xffff`
means, but the stock nonzero entry floor excludes that branch.

### Corrected timing words

For unsigned history word `x` and factor `q`, the instructions implement
`S(x,q) = uint32((uint64(x) * q) >> 15)`. They multiply the low and high
halves separately and add `((low16(x) * q) >> 15)` to
`((high16(x) * q) << 1)` in 32-bit arithmetic.

### Crank capture tick unit

ATU-II channel 0 counts directly from the first prescaler output.
The [Renesas hardware manual](../../../refs/renesas-sh7059-sh7058s-hardware-manual.md)
sections 11.2.2 and 11.2.15 define `PSCR1 = 0x01` at `fffff404`
as a count frequency of `Pphi / 2`. Application startup writes that
value on 1ME3B and 1EK7A. The tick period is `2 / Pphi` seconds,
which is 100 ns at a peripheral clock of 20 MHz. The board clock and
mechanical phase of the captured edge require separate evidence.

The IMI1E and IMI1F cam-capture handlers increment separate byte counters,

for an unrecognized pattern. On tooth 7 the crank handler copies the identified

## Readiness and window result flags

An early readiness branch calls the crank/cam fault-state helper and requires a zero result. It then requires mask `0x60` clear in each of four additional DTC runtime status bytes. Other branches test the operating-state enable, a readiness count of at least one, the unsigned operating-input window `0x06 <= value < 0x5a`, and a battery-voltage snapshot of at least `0x89`. These are firmware predicates on raw values.

The decision path first clears the previous local result bits. It compares each cylinder word with the inclusive floor and builds the new bitmap. The associated repeat counter saturates at `0xff`. The firmware has additional aggregate-report paths, so a count of two cylinders is sufficient to set the aggregate bit in this branch. The branch that copies the highest cylinder share multiplies the maximum of the six cylinder counts by 100 and divides it by the aggregate count after that count reaches a separate runtime word threshold (`fffe9c88` or `fffe9d3c`).

The entry reset zeroes the aggregate and cylinder counter region when `fffeba65 & 0x02` is set on 1ME3B or `fffebe09 & 0x01` is set on 1EK7A. Further readiness failures clear working count and snapshot arrays. Earliest count reset stores in the decision routines are `000cb0f0` and `000d081a`. The result rebuild clears the 1ME3B local flag bits with `and.b 0x80` at `000cc7d6`. It clears the two 1EK7A local flag fields with `and.b 0xf8` at `000d1f28` and `and.b 0x0f` at `000d1f2c`.

## Queue maintenance

Both queue handlers walk the configured eight slots until the `0xffff` index sentinel. The shared first-pass conditions require runtime record byte 2 mask `0x60` and runtime record byte 1 mask `0x20` clear. The next condition differs by layout.

| Queue condition | 1ME3B | 1EK7A |
| --- | --- | --- |
| Handler and caller sites | `000f1db8` from `000c29ee`, `000c2a04` | `00104b9e` from `000c6b8c`, `000c6c08` |
| Runtime status base | `fffed420` | `fffeda10` |
| Additional exclusion condition | Index matches a 32-bit entry in the 30-entry ROM list at `000250d8` (lookup `000f1e1a`, comparison `000f1e1c`, exclusion branch `000f1e90..000f1e92`) | Descriptor byte `ROM8[0001c998 + 12 * index + 8]` has bit `0x04` set (test `00104c46..00104c48`) |
| Queue flag `0x08` readiness | `fffeb9e1 & 0x80` | `fffebd7f & 0x04` |
| Compaction call, after both queue flags `0x08` and `0x04` | `000f1efe` -> `000f1bac` | `00104cb2` -> `00104978` |

The 1ME3B list contains no misfire index from 10 through 16. The 1EK7A misfire descriptors at those indices contain byte 8 value `0x40`, so bit `0x04` is clear. Each variant therefore permits these indices through its extra first-pass filter. The external attribute halfwords used by the publication path are `0x00b0` on 1ME3B and `0x00b8` on 1EK7A for these indices.

The handlers set flag `0x08` when the respective runtime readiness condition is present. The nonzero call argument authorizes flag `0x04`. On 1ME3B the first-pass branch that newly sets `0x08` advances directly to the next slot, skipping the `0x04` set for that slot during the same pass. On 1EK7A both flags may be set in one pass. Both compaction sweeps inspect slots in reverse order and remove entries whose flags already contain both bits.

## Open evidence

- The physical peripheral-clock frequency and mechanical edge phase remain open.
- The physical calibration of the normalized deviation and the upstream meaning of several count-reset state bits require separate evidence.
- The stock predicates establish conditional applicability. The physical detection threshold, monitor completion in vehicle operation and external DTC retention have separate evidence requirements.
