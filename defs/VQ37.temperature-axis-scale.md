# VQ37 VVEL nominal selected and coolant-temperature axes

## Claims and encoded-temperature relation

The axes use a conditional nominal encoded-temperature grid at level `code`.
The effective unit is `degC`, the grid is `x-50`, and its inverse is `x+50`.
The inverse is not a sensor inverse. The claim does not establish measured
coolant temperature, sensor calibration, physical accuracy, or physical
reachability of every breakpoint. There is no hardware proof.

| Meaning | Stock points | Storage | Runtime coordinate | Nominal display |
|---|---|---|---|---|
| `vvel_duration_startup_axis/axis` | 10..160, step 10 | `uint16`, sixteen points | selected temperature | -40..110 degC |
| `vvel_duration_startup_blend_axis/axis` | 100..170, step 10 | `uint16`, eight points | current coolant-coded byte | 50..120 degC |
| `vvel_duration_throttled_ramp_delay_axis/axis` | 20..90, step 10 | `uint8`, eight points | selected temperature | -30..40 degC |

The startup axis exists on JK78C, 1ND0A, 1ND3B, and 1ME3B. The blend and
ramp-delay axes exist only on 1ME3B. The existing absent statuses of JK78C
and 1ND remain independent identity claims. Stored word width does not make
these runtime coordinates wider than an unsigned byte.

The source-word reduction, stock transfer lookup, conditioned publication,
and diagnostic byte use the independently bound contract in
`defs/VQ37.cold-axis-scale.md`. W is an incoming source word, q the stored
byte, T the stock transfer result, P the current conditioned publication,
and A the service-01/PID05 byte.

```text
q = (W >> 2) & 255
T = stock_transfer_lookup(q)
A = max(T - 10, 0)

P = T       if T > old
P = old     if T <= old and T + 2 > old
P = T + 2   otherwise
```

The P relation applies to the normal source-validity branch q=3..241, the
stock transfer-selection flag, and a disabled service override. An override
is a separately declared incoming byte. The retained community PID05 decoder
specifies `A-40 degC`. Therefore `T>=10` implies `A-40=T-50`. Equality of
an axis coordinate with that diagnostic display additionally requires `x=T`
and corresponding samples. Neither current publication nor selected
publication establishes unconditional equality with a live PID.

The decoder is the retained source pack
`refs/diagnostics/public/370z-can-logger/`, dataset
`370z-can-logger-2025-07-05`, document `candata-standard-pids-csv`, and source
row `candata/standard_pids.csv` row 7. Its fragment is
`370z-can-logger-2025-07-05:candata-standard-pids-csv:l0007-l0007:source-row-standard-pids`.
The retained request binds one data byte to service 01 and request 0105.
The pack is `community`, its applicability is `homologous_community`, and
its request is `community_reported`. The parameter's `standard_definition`
is an importer classification, not primary SAE, factory, or hardware evidence.
The executable relation does not promote that source quality.

## Selected publication and exact-image placement

The selected-temperature helper uses an independent flag, threshold, latch,
and previous selected byte. The current P and newly selected result are
executed publications, not incoming computed results.

```text
active = flag bit set and threshold < 100

if active:
    clear latch bit
    refresh = 1
elif latch bit clear:
    set latch bit
    refresh = 1
else:
    retain latch
    refresh = 0

selected = P if refresh else previous_selected
selected_coordinate = snapshot(selected)
coolant_coordinate = snapshot(P)
```

Both branches use the nominal count unit. A retained selection changes the
value and sample age, not the grid. Previous selected is an independent input.
No bound on snapshot age is established. Current coolant and selected
temperature are separate coordinates and must not substitute for one another.

Addresses are hexadecimal. 1ND0A and 1ND3B retain independent exact-image
byte fixtures and independent executions, despite their shared address layout.
Image identities and source paths belong to `rom-images/roms.csv`.

The helper executes its real call, conditional branches, return and delay
slots. Every threshold byte, both flag arms, and both latch arms are checked.
The threshold comparison is unsigned after the stock signed byte load.
Thresholds 99/100 and 127/128/255 distinguish the boundary from a signed
comparison. Latch writes preserve every unrelated bit. The neighboring
normalized-pair lanes are independent inputs, not temperature producers.
Their subsequent helper is excluded.

JK78C executes the six-byte copier `000225c0` with its actual scheduler
call and return. The selected lane loads at `000225de` and stores at
`000225e0`. Its current-coolant lane stores at `000225d8`. 1ND loads/stores
the selected snapshot at `000212d0`/`000212d4`; 1ME3B uses
`000212fc`/`000212fe`. The current-coolant slices remain separately bound.
The copied selected and coolant bytes are never seeded as producer outputs.

Startup uses the selected argument on every image. 1ME3B passes the same
selected byte to the ramp-delay caller. The blend branch instead uses the
current-coolant byte passed as the fifth startup argument. The selected
argument is saved to R14; the current-coolant argument is loaded into R13.
The actual blend call delay slot `00063868` zero-extends R13, while
`00063896` zero-extends selected R14 for the startup lookup. Tests vary
selected and current coolant independently, including selected=106 and
current coolant=87.

## Executable and owner boundary

The unchanged `PathSh2` executes stock instructions in place. There are no
replacement opcode handlers, stubs, relocations, or silently skipped
unsupported instructions. Each independent window records incoming RAM,
registers, stack context, and permitted writes. Unmapped reads, unexpected
ROM reads, executable PCs, writes and neighbor changes fail closed. T, A, P,
new selected, and copied coordinates are executed results. W, old,
previous selected, flag/latch/threshold, unrelated normalized-pair lanes,
request/RPM/state operands, packed upper lanes and return context are
explicit independent inputs.

Static frame geometry is separate from executed integer windows. Selector
net frames are JK78C `0x70`, 1ND `0x60`, and 1ME3B `0x60`. Startup net
frames are JK78C `0x1c`, 1ND `0x1c`, and 1ME3B `0x20`. The ramp-delay
net frame is 1ME3B `0x34`. These FPU-bearing prologues are byte-bound but
not executed. 1ME3B `00063772` loads the fifth argument at SP+0x20.
No simulator return from an excluded FPU function is claimed.

Every coordinate byte executes transport to the actual lookup entry. Full
lookup execution covers declared exact breakpoints and clamped endpoints
only. Fractional paths are excluded before execution, not accepted through
interpreter failures. Axis reads have their actual order, addresses and
widths; returns and delay slots are checked. JK78C/1ND wrappers actually
read the next value word at the upper endpoint. That retained word is
checked and varied independently; phase zero makes the result independent
of it. 1ME3B exact/end-point leaves read only the selected value cell.

Normal accepted q=240/241 yields T=8/7 and A=0, outside the T>=10 relation.
For q=220, old=90 produces selected=P=44 while T=42 and A=32. A retained
previous selected=106 differs from current P=57 and A=47. A service
override P=87 need not correspond to PID05. A later source/PID refresh can
leave both copied coordinates at 57 while A=32. These are executed
counterexamples to unconditional sample equality. Source-word reduction
is many-to-one and `x+50` does not reconstruct the original source word.

Binding negatives reject each new retained span and full-image identity.
Separate supported instruction mutants execute the changed instruction or
its changed literal load and fail the semantic/width/branch/write contract.
Binding rejection, unsupported opcodes, and step limits are not semantic
passes. Mutants distinguish unsigned thresholds, the latch decision,
publication width, selected-copy sources, argument slots and widths,
unsigned extension, axis operands, current/selected substitution and lookup
reads.

The contract excludes sensor/ADC production and calibration, physical
accuracy and reachability, scheduler/interrupt execution and snapshot-age
bounds, fail-safe runtime and initialization, FPU prologues and consumers,
fractional interpolation, complete VVEL functions, diagnostic parser or
wire readiness, actuator behavior, hardware or engine eligibility.
Software gates do not grant flashing approval.
