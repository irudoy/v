# VQ37 running VVEL and intake-CVTC nominal RPM grids

## Claim and independent decoder

`vvel_duration_running_axis/axis` and `intake_cvtc_target_running_axis/axis`
are sixteen-point big-endian `uint16` axes with the nominal RPM grid
`3.125*x`. Their editor-grid inverse is `x/3.125`. This code-level grid is
not a measuring-producer proof and is not a sensor inverse. It carries
no hardware proof, physical accuracy, measured-speed, or reachability claim.

The independently retained fixture is
`tools/mapkit/tests/fixtures/vq37_running_rpm_pid0c.json`.
The actual executable contracts are:

- `tools/mapkit/tests/test_vq37_running_rpm_scale.py#test_vvel_duration_running_nominal_rpm_scale`.
- `tools/mapkit/tests/test_vq37_running_rpm_scale.py#test_intake_cvtc_target_running_nominal_rpm_scale`.

Each JK78C, 1ND0A, 1ND3B and 1ME3B stock image has its own full-image
SHA-256 lock, exact retained instruction/data spans and execution.
`IMAGE_FIXTURES` of the executable module holds those independent locks.
`rom-images/roms.csv` owns image identity and provenance. Shared layout,
identical instructions or identical breakpoints do not substitute one
image's execution for another's and do not supply the physical multiplier.

The decoder is the retained community source
[TihanPelser/370Z-CAN-Logger, standard_pids.csv, row 14](https://github.com/TihanPelser/370Z-CAN-Logger/blob/2decbc957523ee46dd39b3e3a7594e23ad7eee97/candata/standard_pids.csv#L14),
revision `2decbc957523ee46dd39b3e3a7594e23ad7eee97`.
Its fragment is
`370z-can-logger-2025-07-05:candata-standard-pids-csv:l0014-l0014:source-row-standard-pids`.
It states PID 0C, Engine RPM, two data bytes and `((A*256)+B)/4` RPM.
Here the source table's A/B name the first/second response bytes, not the
fine coordinate A defined below. The retained request record binds the
fragment to service 01 and request 010C.

The gate separately pins the document and fragment digests, decoder formula,
request width/identifier/service and parameter/request quality. The pack is
`community` with `homologous_community` applicability, and the request is
`community_reported`. The parameter's `standard_definition` category is an
importer classification, not primary SAE, factory, or hardware evidence.
The code relation does not promote that source quality.

## Bounded relation and exact placement

Let U be an incoming unsigned source word, A its fine-count publication,
R its coarse publication, x the copied fine coordinate and Q the unsigned
word emitted through the two real selected PID0C byte writes.

```text
A = U >> 4
R = U >> 6
A = 4*R + ((U >> 4) & 3)
x = snapshot(A)
Q = min(50*R, 65535)
RPM_PID = Q/4
RPM_grid = 3.125*x
```

The U16 producer domain gives A=0..4095 and R=0..1023, so the PID publisher
does not saturate there. For corresponding samples, fine-coordinate
quantization produces a nominal-grid excess over the coarse PID value of
0, 3.125, 6.25, or 9.375 RPM. The fine word is not exactly four times the
coarse word unless the discarded two bits are zero. This relation does not
recover the low source nibble or establish physical RPM.

Independent updates permit independent snapshot age. A retained coordinate
from one producer sample and a later PID publication need not match.
No upper age bound, simultaneous-sampling guarantee or scheduler atomicity
is inferred from their count units. A demonstrated refresh retains x=640
while a later producer supplies R=200, giving nominal 2000 RPM and decoded
2500 RPM. Distinct U values 10240 and 10255 share A=640, so the inverse
reconstructs only the grid, not the discarded source information.

## Argument, execution and owner boundary

The FPU-inclusive net callee frames are JK78C `0x70`, 1ND `0x60`, and
1ME3B `0x60`. Their exact prologue bytes bind static geometry. The FPU
pushes are not executed.

JK78C reads its copied fine word at `0005545a`, stores the low word of the
packed argument at initial SP+`0x36`, and reads the containing longword at
local SP+`0xa4` through `00056528/0005652a` into R12. An independent upper
lane `0x81a5` verifies that the actual consumer extracts an unsigned word.
The VVEL integer call `0005658c` and its delay slot execute through wrapper
`00028320` and core `000287ac` to the first word at `axis+30`.

The 1ND caller `0005e644..0005f468` loads x at `0005e646`, zero-extends
it and pushes a longword at `0005e64a`. The remaining caller displacement
is `0x30`. The actual callee read `0005f4f0/0005f4f2` loads local
SP+`0x8c` into R13. Separated integer windows retain the fine operand in
R6. The VVEL call at `0005f5de` copies it into R9 in its delay slot.
Wrapper `0002893c` reaches core `00028dc8`, whose first unsigned word
read is at `axis+30`.

The 1ME3B caller `00062180..00062fac` loads x at `00062182` and pushes
its unsigned longword at `00062186`. The remaining caller displacement
is `0x38`. The actual callee read `0006304c/0006304e` loads local
SP+`0x94` into R11. The VVEL call `00063142` places the same fine value
into R9 in its delay slot. Fused leaf `0002af88` reads and zero-extends
the first word at `axis+30`.

Each CVTC caller has an FPU delay slot. Its exact call/delay bytes are
statically bound, not claimed as executed. Its supported integer operand
windows conserve the actual fine argument: R12 for JK78C and the actual
VVEL delay-produced R9 for SH7059. A separately declared callee SP/PR
context executes its wrapper/leaf to the first unsigned word. This does
not claim that the preceding VVEL lookup returned, that the excluded FPU
call executed, or that complete interpolation was performed.

The unchanged `PathSh2` executes stock instructions in place. There are
no opcode extensions, stubs, relocations, or calculated producer-output seeds.
Every execution window declares incoming RAM/register/stack state and permitted
writes. Executed-PC, ROM-load, RAM input/write closure and neighboring guards
fail closed. Full image hashes supplement, rather than replace, independently
retained instruction, literal, axis and source-record bytes.

Retained instruction-only slices also bind static conservation of the actual
RPM argument and wrapper register across the excluded intervals. Each static
slice declares start/end, fallthrough exits and exact branch boundaries.
The structural SH decoder checks conditional and unconditional branch targets,
call/jump targets, delay-slot closure, returns and fallthrough closure against
that manifest. Called helper bodies are closed independently of caller slices;
an unrelated retained address cannot substitute for a declared slice exit.

Every indirect call requires a reaching definition of the actual live pointer.
The declared literal load must reach the transfer on every retained control
path without a pointer-register write. Prior nested calls must conserve that
pointer register through their complete retained bodies. Historical agreement
between a pool load and a JSR register is not sufficient.

The same decoder checks the conserved RPM and wrapper registers, including
nested helpers. This static conservation check is not another execution path.
It supplies no floating-point outputs, replaces no unsupported instruction and
grants no complete-function coverage. 1ND3B's static helper words are
independently byte-bound on its exact image against the shared-layout
instruction expectations. Its producer, snapshot, response, caller, wrapper
and first axis read execute on its own exact image.

The gates cover every fine count and both low-nibble endpoints, all residual
classes, source/byte-cap boundaries, independent filter states, unsigned full
word operands, both PID saturation outcomes, independent snapshot refresh and
