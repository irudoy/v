# JK08A-on-JK00D: write/read-back 2026-07-26

Два чтения main flash стендового JK00D после записи JK08A core always-ID-OK через
PCMFlash 1.2.0, модуль 18, адаптер Scanmatik-SM2 USB. Размер каждого чтения равен
1 048 576 байт. EEPROM в комплект не входит.

## Последовательность

1. PCMFlash с включённой `Проверка/корректировка КС` принял
   `../JK08A_immo-id-ok_CHECKSUMMED.bin` и сообщил `Контрольные суммы корректны`.
   Образ L1+L2 записан, ECU перезагружен, затем выполнено чтение
   `1JK08A_8MFK36N15-20260726-201814.bin`.
2. PCMFlash принял `../JK08A_immo-id-ok.bin` и сообщил
   `Контрольные суммы исправлены`. Образ записан, затем выполнено чтение
   `1JK08A_8MFK36N15-20260726-205657.bin`.

Оба read-back совпадают побайтно:

- MD5: `4a5238cf0fcfcfd8d361895778ce4976`;
- SHA-256: `b9ae5e0150939d10b189ee6f85aa1410b9288f7206ae4fd94135187f02b8dd08`.

## Дельта относительно локального CHECKSUMMED

Read-back отличается от `../JK08A_immo-id-ok_CHECKSUMMED.bin` на 176 байт в двух
диапазонах:

| Диапазон | Размер | CHECKSUMMED input | Read-back |
|---|---:|---|---|
| `0x007000..0x00702f` | 48 | `ff` | блок из исходного JK00D, включая `8MFK36N15` |
| `0x008080..0x0080ff` | 128 | `ee` | нули из исходного JK00D |

Оба диапазона read-back побайтно равны исходному
`../1JK00D_8MFK36N15-20260726-013734/1JK00D_8MFK36N15-20260726-013734.bin`.
Если заменить ими соответствующие диапазоны локального CHECKSUMMED, получается полный
read-back бит в бит. Назначение диапазонов и механизм сохранения не установлены:
PCMFlash мог исключить их из записи, восстановить после записи либо ECU мог записать их
при перезагрузке. Наличие идентификатора не доказывает семантику остальных полей;
таймстамп, счётчик, производственные или иные данные остаются гипотезами.

Диапазоны находятся до `0x008200` и не входят в локализованные SUM16/runtime-selftest
домены JK03A/JK08A. В обоих read-back:

- L1 по `0x08d7c8` равен `0009`;
- L2 по `0x0938be` равен `0009`;
- SUM16 A/B равны `9ec0` / `96e6`;
- selftest A XOR/SUM равны `88af0b53` / `3a4f1fcf`;
- selftest B SUM/XOR равны `ac399870` / `07131670`;
- все шесть хранимых значений совпадают с повторным расчётом.

## Вывод и границы

Первое чтение подтверждает сохранность записанного CHECKSUMMED после перезагрузки ECU
за исключением двух стабильных диапазонов исходного JK00D неизвестного назначения.
Второе чтение подтверждает, что auto-correction PCMFlash для образа без
checksum-постфикса приводит известные checksum fields и весь остальной ROM к тому же
результату, что локальный пересчёт. Совпадение двух полных read-back также показывает стабильность неизвестных
диапазонов между двумя операциями записи.

Эксперимент не подтверждает назначение диапазонов, чтение EEPROM, stock restore,
аварийное recovery, поведение NATS/BCM, DTC P1610-P1615, crank или запуск двигателя.
