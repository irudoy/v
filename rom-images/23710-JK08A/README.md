# 23710-JK08A – исходный ROM

Собственный дамп физического целевого ЭБУ `23710-JK08A` автомобиля V36 Skyline 250GT,
снятый 2026-07-26 через PCMFlash 1.2.0, модуль 18 `Nissan: EFI SH705822N,
SH705828N (Hitachi SH7058/1MB)`, адаптер Scanmatik-SM2 USB.

## Состав

- `1JK08A-20260726-stock.bin` – flash-ROM, 1 048 576 байт
  (`0x100000`);
- `1JK08A-20260726-stock.bin.md5` – MD5 sidecar;
- `mods/immo-off/` – однобитовый immo-off.

Хеши ROM:

- SHA-256: `ab60f18793fb121e4f55f626246117a6c69d9a900c0307ab1f4fc5f6ac718b23`;
- MD5: `db4eeb16e6385afcb69e70955147c483`.

MD5 совпадает со значением, созданным PCMFlash при чтении. Снимок экрана
идентификации PCMFlash в комплекте отсутствует.

## Идентификация

Данные PCMFlash и строки внутри образа согласуются:

| Поле | Значение | Смещение в ROM |
|---|---|---:|
| ECM part # | `23710-JK08A` | идентификация PCMFlash |
| Калибровка | `1JK08A00000` | `0x8204` |
| Основной номер / идентификатор ПО | `7MFKAVN86` | `0x6f09`, `0x2259c` |
| Класс EFI / MCU | `SH705822N` | `0x50c6` |
| Протокол | Hitachi CAN | профиль модуля PCMFlash |

Комплект содержит только главный flash-ROM. Отсутствие файла EEPROM не доказывает
отсутствие внешнего EEPROM на плате; его наличие и содержимое остаются отдельной
задачей.

## Сопоставление с JK03A

Донорский `JK03A` имеет тот же размер, MCU и идентификатор ПО `7MFKAVN86`.
Между образами различается 121 байтовая позиция в 58 непрерывных диапазонах, только
в интервале `0x008200..0x0190c9`. Области совпадают побайтно:

- `0x000000..0x0081ff`, SHA-256
  `d3b00d4ea983f0eaaa2085af4c79f087c8a6256379b11e5f962eefd121a4c902`;
- `0x020000..0x0fffff`, SHA-256
  `34726ad5cf8a81b632502102887273dad7c45e4e0a4f380163d251b386bb4c9e`.

Дельта включает ROM ID, checksum, четыре известные 1D-16 `uint16` кривые по
`0x15360`, `0x15380`, `0x19090`, `0x190b0`, диагностические дескрипторы и другие
config/calibration данные. Отдельный слой Memgraph `JK08A` использует общую структуру
exact-code пары, но измеряет значения по этому образу. Рабочий `defs/JK08A.xml` не
публикует четыре отличающиеся безымянные candidate-кривые; остальные опубликованные
таблицы и оси совпадают с донором побайтно.

## NATS: флаг Developer Immobilizer

Исполняемый код JK08A совпадает с JK03A. Заводской флаг по `0x8725` также совпадает:
stock-значение `01`, immo-off `00`. Изменение сбрасывает только bit0.

Bit0 читают четыре функции: `0xA3F96`, `0xBBC88`, `0xBC82E` и `0xBC9E4`.
При нуле `0xBC82E` очищает `0xFFFF55E4.bit2`, после чего `0xBC9E4` очищает
`0xFFFF4198.bit1` motor inhibit. Состояния registered `0xFFFF41C1.bit0`,
registered ch1 `0xFFFF41C2.bit6` и Lock `0xFFFF4201.bit2` относятся к соседнему
статусному контуру.

Производный `mods/immo-off/1JK08A-20260727-immo-off.bin` имеет SHA-256
`de7f99cfb592d1cd1d83706f08cbea99ad0aef8602090d009cb37e9d37080d8c` и
отличается от этого stock-образа только `0x8725: 01 -> 00`. Исполнительная цепочка
имеет статус `code`; проверка запуска и наблюдение DTC на машине ожидаются.
