# 1JK08A immo-off

Однобитовый мод для `23710-JK08A`, выпущенный 2026-07-27 из точного
`../../1JK08A-20260726-stock.bin`.

## Состав

- `1JK08A-20260727-immo-off.bin` – производный flash-ROM, 1 048 576 байт
  (`0x100000`);
- `1JK08A-20260727-immo-off.bin.md5` – MD5 sidecar.

Хеши ROM:

- SHA-256: `de7f99cfb592d1cd1d83706f08cbea99ad0aef8602090d009cb37e9d37080d8c`;
- MD5: `1ae5f50b6f8697b168285b92ade28b7b`.

## Изменение

```text
ROM[0x00008725]: 0x01 -> 0x00
```

Изменяется только bit0 заводского флага Developer Immobilizer. Производный образ
отличается от stock ровно одним битом. Хранимые checksum-поля совпадают со stock;
контрольные суммы корректирует флешер при записи.

Патч воспроизводится командой:

```bash
python3 patches/apply_immo_off.py --rom JK08A
```

Исполнительная цепочка подтверждена кодом. Проверка запуска, NATS DTC и
security-индикатора на машине ожидается.
