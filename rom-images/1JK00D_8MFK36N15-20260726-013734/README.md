# 23710-JK00D – исходный ROM

Собственный дамп физического стендового ЭБУ `23710-JK00D`, снятый 2026-07-26
через PCMFlash 1.2.0, модуль 18 `Nissan: EFI SH705822N, SH705828N
(Hitachi SH7058/1MB)`, адаптер Scanmatik-SM2 USB.

## Состав

- `1JK00D_8MFK36N15-20260726-013734.bin` – flash-ROM, 1 048 576 байт
  (`0x100000`);
- `1JK00D_8MFK36N15-20260726-013734.bin.md5` – MD5-файл PCMFlash;
- `1JK00D_8MFK36N15-20260726-013734.png` – снимок успешной идентификации
  PCMFlash.

Хеши ROM:

- SHA-256: `e2d7a374b4f7cb42d1963e7aeea424f2147ef01afd231f31b599d83f87f315d3`;
- MD5: `e22136ffcb90319c4e1ab678d0ee5fbe`.

## Идентификация

PCMFlash и строки внутри образа согласуются:

| Поле | Значение | Смещение в ROM |
|---|---|---:|
| ECM part # | `23710-JK00D` | идентификация PCMFlash |
| Калибровка | `1JK00D00000` | `0x8204` |
| Основной номер / идентификатор ПО | `8MFK36N15` | `0x7009` |
| Класс EFI / MCU | `SH705822N` | `0x50C6` |
| Протокол | Hitachi CAN | идентификация PCMFlash |

Комплект содержит только главный flash-ROM. Отсутствие файла EEPROM не доказывает
отсутствие внешнего EEPROM на плате; его наличие и содержимое остаются отдельной
задачей.

## Сопоставление с JK03A

Образ не является другой копией донорского VQ25HR `JK03A`: при одинаковом размере
различаются 830 836 байтовых позиций, первая по `0x7000`, последняя по `0xDE74B`.
Перенос адресов кода, карт и checksum между ROM требует структурной гомологии.

## NATS: структурный перенос

Статический перенос патча ECM-side "always ID OK" локализован по гомологии с JK03A
и подтверждён Ghidra 12.1.2:

| Узел | Функция / адрес | RAM-состояние |
|---|---|---|
| registration | `FUN_00098908` | registered `0xffff4374` b0, ch1 `0xffff4375` b6 |
| evaluator-подобная функция | `FUN_00098d6e`, канал `r4=0/1` | вход registration |
| lock_setter | `FUN_000923e4` | Lock `0xffff43b8` b3, counter `0xffff559e` |
| DTC-якоря | `0x01c6e6..0x01c722` | P1610-P1615 |

Точки патча:

- L1 Lock-suppress: `0x092488`, `cf 08` -> `00 09`;
- L2 registered-force: `0x0989ea`, `89 09` -> `00 09`;
- L2b reset-clear: `0x098976`, `cd fe` -> `00 09`;
- L2' ch1 force: `0x0989be`, `8d 08` -> `00 09`;
- L2b' ch1 reset-clear: `0x098972`, `cd bf` -> `00 09`.

Полный скан записей в Lock-байт находит ровно один setter bit3: L1 по `0x092488`.
Все пять исходных последовательностей проверяются командой:

```bash
python3 patches/apply_immo_patch.py --rom JK00D --with-l2b --with-esc --verify-only
```

Патченый образ не создан. Статус переноса – `code`, не `silicon`: checksum-схема
JK00D не локализована, а запись, восстановление стока, BCM-handshake, crank, запуск
и отсутствие P1610-P1615 требуют проверки на стенде. Комплект не содержит EEPROM.
