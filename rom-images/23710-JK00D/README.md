# 23710-JK00D – исходный ROM

Собственный дамп физического стендового ЭБУ `23710-JK00D`, снятый 2026-07-26
через PCMFlash 1.2.0, модуль 18 `Nissan: EFI SH705822N, SH705828N
(Hitachi SH7058/1MB)`, адаптер Scanmatik-SM2 USB.

## Состав

- `1JK00D-20260726-stock.bin` – flash-ROM, 1 048 576 байт
  (`0x100000`);
- `1JK00D-20260726-stock.bin.md5` – MD5 sidecar;
- `1JK00D-20260726-pcmflash-identification.png` – снимок успешной идентификации
  PCMFlash.

Хеши ROM:

- SHA-256: `e2d7a374b4f7cb42d1963e7aeea424f2147ef01afd231f31b599d83f87f315d3`;
- MD5: `e22136ffcb90319c4e1ab678d0ee5fbe`.

## Идентификация

PCMFlash и строки внутри образа согласуются:

| Поле | Значение | Смещение в ROM |
|---|---|---:|
| ECM part # | `23710-JK00D` | идентификация PCMFlash |
| Калибровка | `1JK00D00000` | `0x8204` |
| Основной номер / идентификатор ПО | `8MFK36N15` | `0x7009` |
| Класс EFI / MCU | `SH705822N` | `0x50C6` |
| Протокол | Hitachi CAN | идентификация PCMFlash |

Комплект содержит только главный flash-ROM. Отсутствие файла EEPROM не доказывает
отсутствие внешнего EEPROM на плате; его наличие и содержимое остаются отдельной
задачей.

## Сопоставление с JK03A

Образ не является другой копией донорского VQ25HR `JK03A`: при одинаковом размере
различаются 830 836 байтовых позиций, первая по `0x7000`, последняя по `0xDE74B`.
Перенос адресов кода, карт и checksum между ROM требует структурной гомологии.

## NATS: флаг Developer Immobilizer

Гомологичный конфигурационный флаг находится по `0x8740`; stock-значение `01`,
immo-off `00`. Bit0 читают четыре гомологичные функции:

| Функция | Роль |
|---|---|
| `FUN_000A92E0` | монитор состояния |
| `FUN_000C1754` | основная state machine |
| `FUN_000C233A` | нормализация переходов и состояния запрета |
| `FUN_000C24EE` | формирование motor inhibit |

`patches/apply_immo_off.py --rom JK00D --verify-only` проверяет точный stock ROM,
SHA-256 и исходное значение байта. Производный образ JK00D не хранится. Структурная
гомология имеет статус `code`; проверка запуска на стенде ожидается.

## Использование как подменного ЭБУ

Физический JK00D использован как target для точного образа JK08A
`../23710-JK08A/mods/immo-off/1JK08A-20260727-immo-off.bin`. Аппаратная проверка
2026-07-27 на V36 Skyline 250GT с VQ25HR подтвердила запуск и исправную работу
двигателя. ECM сохраняет DTC P1610 после очистки, но ошибка не влияет на запуск.

Этот результат подтверждает JK08A immo-off по `0x8725`, но не является аппаратной
проверкой собственного флага JK00D по `0x8740`.
