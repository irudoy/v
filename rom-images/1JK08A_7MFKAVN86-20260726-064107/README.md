# 23710-JK08A – исходный ROM

Собственный дамп физического целевого ЭБУ `23710-JK08A` автомобиля V36 Skyline 250GT,
снятый 2026-07-26 через PCMFlash 1.2.0, модуль 18 `Nissan: EFI SH705822N,
SH705828N (Hitachi SH7058/1MB)`, адаптер Scanmatik-SM2 USB.

## Состав

- `1JK08A_7MFKAVN86-20260726-064107.bin` – flash-ROM, 1 048 576 байт
  (`0x100000`);
- `1JK08A_7MFKAVN86-20260726-064107.bin.md5` – MD5-файл PCMFlash.

Хеши ROM:

- SHA-256: `ab60f18793fb121e4f55f626246117a6c69d9a900c0307ab1f4fc5f6ac718b23`;
- MD5: `db4eeb16e6385afcb69e70955147c483`.

MD5 совпадает со значением в sidecar-файле PCMFlash. Снимок экрана идентификации
PCMFlash в комплекте отсутствует.

## Идентификация

Данные PCMFlash и строки внутри образа согласуются:

| Поле | Значение | Смещение в ROM |
|---|---|---:|
| ECM part # | `23710-JK08A` | идентификация PCMFlash |
| Калибровка | `1JK08A00000` | `0x8204` |
| Основной номер / идентификатор ПО | `7MFKAVN86` | `0x6f09`, `0x2259c` |
| Класс EFI / MCU | `SH705822N` | `0x50c6` |
| Протокол | Hitachi CAN | профиль модуля PCMFlash |

Комплект содержит только главный flash-ROM. Отсутствие файла EEPROM не доказывает
отсутствие внешнего EEPROM на плате; его наличие и содержимое остаются отдельной
задачей.

## Сопоставление с JK03A

Донорский `JK03A` имеет тот же размер, MCU и идентификатор ПО `7MFKAVN86`.
Между образами различается 121 байтовая позиция в 58 непрерывных диапазонах, только
в интервале `0x008200..0x0190c9`. Области совпадают побайтно:

- `0x000000..0x0081ff`, SHA-256
  `d3b00d4ea983f0eaaa2085af4c79f087c8a6256379b11e5f962eefd121a4c902`;
- `0x020000..0x0fffff`, SHA-256
  `34726ad5cf8a81b632502102887273dad7c45e4e0a4f380163d251b386bb4c9e`.

Дельта включает ROM ID, checksum, четыре известные 1D-16 `uint16` кривые по
`0x15360`, `0x15380`, `0x19090`, `0x190b0`, диагностические дескрипторы и другие
config/calibration данные. Деф JK03A нельзя считать побайтным дефом JK08A.

## NATS: exact-code перенос

Исполняемый код и все пять NATS patch-sites JK03A совпадают побайтно. RAM-модель
остаётся той же: registered `0xffff41c1` b0, ch1 `0xffff41c2` b6, Lock
`0xffff4201` b2.

Точки патча:

- L1 Lock-suppress: `0x08d7c8`, `cf 04` -> `00 09`;
- L2 registered-force: `0x0938be`, `89 09` -> `00 09`;
- L2b reset-clear: `0x09384a`, `cd fe` -> `00 09`;
- L2' ch1 force: `0x093892`, `8d 08` -> `00 09`;
- L2b' ch1 reset-clear: `0x093846`, `cd bf` -> `00 09`.

Консервативная sole-setter проверка находит один setter bit2 в поддерживаемых формах:
L1 по `0x08d7c8`. Семь индексных RMW-записей в тот же байт выверены Ghidra и меняют
только b0/b3/b4/b5/b7 с сохранением Lock b2; опасных или непроверенных store не остаётся.
Stock-образ самосогласован по двум SUM16 и runtime selftest XOR+SUM A/B.

Подготовлены локальные checksum-корректные артефакты:

- `../JK08A_immo-id-ok_CHECKSUMMED.bin` – L1+L2, кандидат первой hardware-проверки;
- `../JK08A_immo-id-ok_l2b_esc_CHECKSUMMED.bin` – L1+L2+L2b+L2'/L2b', условный
  fallback.

Статус переноса и checksum – `code/offline`, не `silicon`. Запись, восстановление
stock, поведение PCMFlash/SM2PRO при коррекции checksum, BCM handshake, crank, запуск,
DTC P1610-P1615 и EEPROM требуют отдельной hardware-проверки.
