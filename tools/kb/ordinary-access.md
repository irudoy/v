# Ordinary access-proof registration

`src/kb/ordinary_access_registry.py` owns the shared registration of existing
access families that publish exact ordinary `link` appends. Each `Family`
entry declares its canonical mode, contract/evidence/resolution modules,
ordered required capture producers, descriptor and non-glob source files,
direct-owning level policy and original-owner fallback policy.

The contract module retains its exact namespace, original claim identities,
full native preimages/postimages and operation shapes. Its evidence module
retains independent raw consumers and their required domain flags. Its
resolution module retains exact grouped publication and retirement. A registry
entry routes these existing hooks; it cannot establish an access or qualify a
new domain result.

## Coherent source-group preparation

Group preparation reuses successful normal KB graph/code responses and the
documented Ghidra decompiler/listing cache. A reusable group description records:

- Exact original claim hashes, canonical claims, owners and source-prepared
  disposition references. Subtraction uses original hashes rather than function
  membership or the number of proposed native operations.
- Shared function or explicit bounded call sequence, saved normal process and
  stdout identities, cached code files and their declared cache key/digests.
- Full native owner preimages already obtained through the normal owner path,
  with missing or conflicting owners left for an explicit normal read.
- Existing reconstruction units, raw components and independent consumers that
  can be reused. Function/span membership remains a structural candidate.
- The missing evidence for the complete shared boundary: incoming GBR/index
  premises, natural call and post-delay arguments, exact datum/site/width/
  direction, independent causal equations and fixed-other variation, relevant
  branches/returns, native disposition, original TEST positions and refusals.

Accepted cached output digests bind the saved structural source. Current
program-state validation is recorded separately; a saved cache key alone does
not establish current code or semantic admission. Source-prepared claims remain
unqualified until the complete original execution and native publication gates
admit them. Preparation artifacts and copied inspection outputs are local
results, outside tracked firmware and canonical knowledge.

## Required regression boundary

The mandatory source coverage gate discovers contracts that expose the ordinary
access hooks and requires one authoritative entry for each. Narrow regression
sources reject missing, duplicate and inconsistent registration, capture or
consumer coverage, source omissions and namespace ambiguity. They retain
direct-owning admission/coordinate/RPM behavior, exact complete writer batches,
full native and TEST preservation, unique scope-neutral attachments and
identity-only/no-reverse-donation behavior. Per-domain executable and native
tests remain independent requirements of the shared acceptance boundary.
